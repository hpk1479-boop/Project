# 테스트 스페셜 전략 보관

파트3에서 만든 전략은 이 폴더에 저장합니다. Python 파일과 같은 번호의 `.recipe.json`은 함께 보관하세요. 화면에서 이름을 변경해도 번호와 파일명은 유지됩니다.

처음 생성한 전략은 파트3 목록에만 표시됩니다. 메인전략 승급을 누르면 파트1·파트2에 함께 등록됩니다. 승급해도 파일은 이 폴더에 남으며 라이브 사용은 자동으로 켜지지 않습니다.

파트1·파트2의 목록에서 제외는 해당 파트의 등록만 제거합니다. 파트3에서 전략 삭제를 선택하면 경고 확인 후 실제 파일과 양쪽 등록·설정을 삭제합니다. 리셋으로 실제 삭제한 파일을 복구하지 않습니다.

이 폴더의 전략은 승급 여부와 관계없이 새 배포본에서 제외합니다. 정식 배포 대상은 `Part1/program/SPECIAL`입니다. 필요하면 새로 생성한 현재 형식의 전략 파일을 정식 폴더로 복사하고 중복되지 않는 `SPECIAL번호.py` 이름을 사용하세요.

이전 수정본의 샘플 파일은 내용 변경 없이 옮겼습니다. 이전 형식이거나 코드와 설정이 일치하지 않는 파일은 화면에 확인할 수 없는 전략으로 표시하며 삭제만 가능합니다. 파일을 직접 수정한 뒤 등록하거나 실행하는 수동 코드 모드는 지원하지 않습니다.
