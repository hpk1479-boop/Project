# 프로그램 종료

- X를 처음 누르면 정상 중지와 저장을 바로 시작합니다. 종료 중 안내를 표시하며 별도 선택창을 먼저 띄우지 않습니다.
- 종료 중 X를 다시 누르면 `강제 종료하시겠습니까?`를 예·아니요로 확인합니다. 아니요는 정상 종료를 계속 기다리고, 예는 저장 대기와 독립적으로 관리 프로세스를 강제 종료한 뒤 현재 프로그램을 즉시 종료합니다.
- 백테스트·데이터 구축·라이브 감시만 실행 중·작업 없음 모두 같은 흐름입니다. 기존 세 버튼 선택창과 그 상태 분기·초기 작업 조회 조건을 제거했습니다.
- 강제 종료는 이 프로그램의 관리 작업 및 해당 설치의 라이브·공통 AI 프로세스만 대상으로 합니다. PID와 생성 시각을 재확인하고 원래 프로세스 핸들을 유지하여 다른 프로세스와 PID 재사용을 보호합니다.
- 정상 저장이 끝나면 기존 결과 저장과 공통 AI 종료 확인, 서버·창 정리를 유지합니다. 강제 종료 시 저장되지 않은 결과는 유실될 수 있습니다.

검증: 종료·저장·재시작 단위/회귀 89개 통과. 격리된 Windows 프로세스에서 저장 스레드가 계속 기다려도 프로그램이 실제 종료됨을 확인했습니다. 가짜 공통 AI 프로세스와 자식은 종료되고 무관한 Python 프로세스는 유지됨을 확인했습니다. 증거는 `검증결과/revision111/window_close/`에 있습니다.
