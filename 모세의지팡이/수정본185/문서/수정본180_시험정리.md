## 11. 실행 방법

```
python -B -m pytest -q -p no:cacheprovider --basetemp %TEMP%\p180 tests Part3/tests
set PYTHONPATH=통합설치
python -B -m pytest -q -p no:cacheprovider --basetemp %TEMP%\r180 통합설치/releasekit/tests
python verify_current.py
```

`PYTHONUTF8=1`, `PYTHONDONTWRITEBYTECODE=1`. 공식 검사기는 `verification/` 93파일을 파일마다 따로(외부망·작업본 AI 차단) 돌리고, Python·JS 문법 검사와 목록 검사를 한다.
