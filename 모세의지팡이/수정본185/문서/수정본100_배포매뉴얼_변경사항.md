# 수정본100 배포 도구·매뉴얼 변경사항

개발자용 배포 실행 파일은 루트의 `모세의지팡이 배포.cmd`입니다. 내부 PowerShell 파일도 `통합설치/모세의지팡이 배포.ps1`로 이름을 맞췄으며 이전 이름의 중복 실행 파일은 남기지 않았습니다.

설정창은 `모세의지팡이 배포`, 생성 버튼은 `모세의지팡이 통합설치 만들기`입니다. 만료일 선택에 1개월·3개월·6개월·12개월을 제공합니다. 달력 월 기준으로 계산하며 해당 날짜가 다음 달에 없으면 월말에 맞춥니다. 날짜 직접 입력과 설치 유효시간 입력은 유지합니다.

설치파일은 `배포/<지정 버전>_<빌드번호>/모세의지팡이 통합설치.exe`에 생성됩니다. 지정 버전은 폴더와 EXE 버전 정보, 서명된 라이선스에 기록됩니다.

개발자 매뉴얼 전용 폴더는 `매뉴얼`입니다. 배포 PDF는 `매뉴얼/모세_사용자_매뉴얼.pdf`, 편집 원본은 `매뉴얼/편집원본/제작.py`입니다. 기존 문서 폴더의 PDF는 전용 폴더로 옮겼으며 중복 보관하지 않습니다. 제작 원본은 자기 위치를 기준으로 경로를 찾아 다음 수정본에도 옮겨 사용할 수 있습니다.

배포 도구는 매번 현재 수정본의 PDF를 읽어 포함합니다. 설치와 업데이트 모두 `MOSES/매뉴얼/모세_사용자_매뉴얼.pdf`에 배치하며 새 PDF로 교체합니다. 편집 원본·편집 안내·이전 PDF는 배포에 포함하지 않습니다. 원본 PDF, 배포 복사본, 통합설치 ZIP의 용량과 SHA-256을 비교합니다. 매뉴얼 누락, PDF 형식 표시 오류, 빌드 중 변경·삭제가 감지되면 발급을 중단하고 미완성 EXE도 제거합니다. 보고서의 `manual`에 경로·용량·해시를 남깁니다.

원본 Part1·Part2·Part3·공통 AI·언어사전·설정·실행 파일 2,362개를 작업 전과 비교해 변경이 없음을 확인했습니다. 수정본100을 만들 때의 전체 기준 목록도 별도로 비교했습니다. 변경 범위는 배포 도구·검사·안내 및 검증 기록입니다. 전략·계산·라이브 실행·AI 계약 코드는 변경하지 않았습니다.

검증 결과:

- 전체 배포 도구 검사: 319개 통과, 세부 검사 48개 통과.
- 실제 새 CMD/PS1 실행, 한글·공백 경로 이동, 설정창 표시와 날짜 버튼 확인.
- 연속 빌드의 최신 PDF 반영, 편집 원본 제외, 빌드 중 원본·복사본·ZIP 변경 차단 확인.
- C# 설치 시험: 첫 설치의 PDF 일치, 업데이트 시 PDF 교체·이전 관리 PDF 정리·사용자 자료 보존, 파일 잠금 실패 시 롤백 확인.
- 실제 배포 EXE: 라이브러리 83개, 화면·도움말 요청 33개, WebView 화면 3개 검사 통과.
- 실제 통합설치 EXE 리소스에서 PDF를 읽어 개발자 PDF와 SHA-256 일치 확인. 편집 원본 미포함, 지정 버전과 한글 파일명 확인.
- 빌드 종료 후 `.work`, `prerequisites`, `.buildenv` 정리 확인. 검증용 설치파일은 삭제하고 결과 기록만 보관.

실제 빌드 검증에서는 이 PC의 기존 빌드 의존성 환경과 서명을 확인한 WebView2 설치파일을 재사용했습니다. 사용자가 배포 버튼을 누를 때에는 기존처럼 필요한 준비 파일을 다운로드하고 완료 뒤 정리합니다. 네이티브 설치 시험은 격리된 임시 폴더에서 수행했으며 실제 사용자 설치·MT5 위치·바탕화면·등록 정보는 변경하지 않았습니다.

요약 증거는 `검증결과/release100`에, 실제 빌드별 상세 검사는 `검증결과/license96/<빌드번호>`에 있습니다.
