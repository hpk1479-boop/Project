# 수정본111 작업 내역

수정본110을 복사하여 수정본111에서 작업했습니다. 가상진입·ATR 설정 변경은 이번 작업에서 제외했습니다.

## 적용한 동작

- 설치 성공 시 설치창이 자동으로 닫힌 다음 실행한 설치 EXE를 삭제합니다. 실패·취소에는 성공 삭제를 실행하지 않습니다. 파일 잠금이 있으면 같은 설치 EXE만 확인하여 삭제를 재시도합니다.
- 설치 폴더 바로 아래 `MT5`에 유효기간을 적용한 EA·PRICE·RSI·STO·DI EX5 5개를 제공합니다. MT5 자동 설치에 쓰는 내부 파일과 같은 파일인지 배포 검증에서 확인합니다. 개발자 MQ5·MQH·EX5는 변경하지 않았습니다.
- 백테스트·데이터 구축 취소와 프로그램 X 닫기는 첫 클릭에서 정상 중지·저장을 시작합니다. 종료 중 다시 누르면 “강제 종료하시겠습니까?”를 확인합니다. 예는 해당 작업 또는 프로그램을 강제 종료하고, 아니요는 정상 종료를 계속 기다립니다.
- 기존 3개 버튼 선택창, 초기 백테스트 전용 종료 조건, 선택창용 구조체와 이전 취소 분기를 제거했습니다. 정상 결과·라이브 상태 저장은 유지합니다.
- Windows Python 실행기가 자식 엔진을 만드는 경우, 이번 실행의 토큰·프로세스 계층·생성 시각을 확인하여 실제 엔진의 준비 상태를 읽습니다. 실행기 자체를 별도 엔진으로 표시하지 않습니다.
- 정상 종료 중 MT5 연결 해제는 카드 오류로 표시하지 않습니다. EVENT의 단순 처리 지연은 로그에 남기며 실제 처리 오류와 구분합니다.
- 종료 중 경제 알림의 전송 확인 대기를 해제합니다. 전송하지 않은 알림을 전송 완료로 기록하지 않습니다.
- 엔진 제어 상태 파일을 순간적으로 읽는 동안 Windows 파일 교체가 거절되면 짧게 재시도합니다. 지속되는 저장 오류는 운영체제 원인까지 로그에 남깁니다.

## 확인

- 라이브 관련 회귀 검증 142개 통과.
- 기존 개발자 실행 환경으로 실제 MT5 연결·종료·즉시 재시작을 두 번 확인했습니다. 최종 실행은 시작 2.7~2.9초, 종료 약 1.2초였고, 강제 종료 없이 상태 저장을 완료했습니다.
- 정상 종료 대기 중 검증용 실제 엔진을 강제 종료하는 데 0.418초가 걸렸습니다. 다른 Python 프로세스는 유지됐습니다.
- 창 종료 검증 89개와 하위 검사 10개 통과. 백테스트 취소 검증 83개와 하위 검사 18개, 브라우저 취소 검증 8개 통과.
- 설치·배포 회귀 검증 197개와 하위 검사 107개 통과. 실제 설치 EXE 자동 닫기·삭제 및 잠금 재시도를 확인했습니다.
- 실제 MetaEditor로 유효기간 적용 EX5 5개를 컴파일하고 원본 불변 및 내부·외부 MT5 파일 일치를 확인했습니다.
- 원본 Python 파일 없이 배포 번들 300개 모듈을 만들고 새 종료·취소·라이브 제어 API 포함 및 실행을 확인했습니다.
- 매뉴얼은 설치·MT5·종료 안내를 갱신하고 변경 페이지를 렌더링 확인했습니다.

검증 증거는 `검증결과/revision111`에 있습니다. 실제 소요 시간은 이 PC에서 측정한 값입니다. 최종 대용량 Setup EXE 생성과 Python 없는 별도 PC 설치는 이번 검증에서 수행하지 않았습니다.

기존 결과 조회 오류 후 재시도에 관한 브라우저 회귀 검사 1개는 수정본110에서도 같은 실패가 발생했습니다. 이번 종료·취소 변경 범위와 분리하여 `backtest_cancel/baseline110`에 증거를 남겼습니다.
