# 수정본113 가상진입 화면 및 수동 실행 전달

가상 진입을 선택했을 때만 진입 방식·확인 조건·ATR 제한·손절 기준을 설정합니다. 알림 온리와 데이터 구축은 가상진입 설정을 보내지 않으며, 숨겨진 가상진입 입력 때문에 실행을 막지 않습니다.

## 화면

- 자동: 올존은 공통 확인 진입의 HMA6 기본 설정, 다른 알림은 즉시 진입입니다.
- 즉시 진입: 확인 조건 편집을 숨깁니다. ATR 진입 제한과 손절 설정은 적용할 수 있습니다.
- 확인 진입: 매수는 직전 확정봉 양봉, 매도는 직전 확정봉 음봉을 확인하고 현재 봉 시가에 진입합니다. 이평 위·아래, 이평 종가 돌파, 이평 터치 후 확인, 인걸핑, 해당 올존의 넥라인 종가 돌파를 추가·삭제할 수 있습니다. 추가한 조건은 모두 충족해야 합니다.
- 이평: SMA·EMA·WMA·HMA와 기간·프레임을 지정합니다. 추가 조건이 없으면 기본 봉 방향만 확인합니다.
- `신호 프레임 · 자동`: 일반 전략은 전략 조건의 가장 낮은 프레임, 올존은 실제 올존 발생 프레임을 사용합니다.
- ATR 진입 제한: 접힌 선택사항으로 제공합니다. 직전 확인봉 몸통/전체 크기와 현재 시가의 이평 거리를 ATR 배수로 제한합니다. 최소는 포함, 최대는 제외입니다. 제한 한쪽은 비워둘 수 있으며 둘 다 비우려면 해당 제한을 삭제합니다.
- 손절: 자동, 올존 B0, 직전 N개 확정봉의 저점·고점, ATR 배수입니다. N봉/ATR을 선택할 때 필요한 입력만 표시합니다.
- 기존 1:1부터 1:5까지 0.5 간격의 9개 손익비 계산을 유지합니다.

숫자는 입력 즉시 설정에 반영됩니다. 다른 입력칸이나 화면 바깥을 클릭할 필요가 없습니다. 화면을 오가거나 목록을 새로 불러와도 현재 편집값을 유지합니다. 정상적인 가상진입 실행 요청을 만들면 해당 정책만 저장하고, 다음에 화면을 열 때 복원합니다. 전략 목록·텔레그램·다른 백테스트 설정은 함께 덮어쓰지 않습니다.

## 공통 계약

`unified_backtest.options()`는 Part2 공통 계약에서 정규화한 정책과 공통 Fact의 프레임 목록을 반환합니다. `_scenario()`는 가상진입 실행에만 `normalize_virtual_entry()`로 검증한 정책을 Part2에 전달하고 `ui_model.save_virtual_entry()`로 해당 정책만 보관합니다. 임의의 자연어 판정, 별도 HMA6 체결 경로, 다른 엔진 실행 기능은 화면에 추가하지 않았습니다.

서버가 정책을 거절하면 설정 화면에 오류를 표시하고 실행 버튼은 다시 사용할 수 있습니다. 예: `ATR 최대 배수는 최소 배수보다 커야 합니다.`

기존 결과표에는 `순서 미확정` 한 칸을 추가했습니다. 즉시 진입한 첫 1분봉에서 진입 전후의 손절·익절 접촉 순서를 확정할 수 없는 거래입니다. 진입 수에는 포함하고 승패·승률·평균 R에서 제외합니다. 거래내역의 청산 시각은 이 경우 `—`로 표시하며 원시 CSV의 판정 시각은 보존합니다. 확정된 WIN/LOSS의 청산 시각은 그대로 표시합니다.

변경 파일: `Part3/web/index.html`, `Part3/web/unified.js`, `Part3/web/style.css`, `Part3/web/backtest_dashboard.js`, `Part3/lab/unified_backtest.py`. 신규 회귀검증: `Part3/tests/test_virtual_entry_ui113.cjs`, `Part3/tests/test_virtual_entry_web113.py`.

## 확인 결과

- 새 수동 정책 전달 5개와 기존 웹/헤드리스/로컬 HTTP 검증을 합쳐 23개, 추가 부분검증 18개 통과.
- 실제 HTML/CSS/JavaScript를 격리된 Edge에서 실행한 화면 검증 11개 통과. 모든 확인 조건의 추가·삭제, ATR 두 제한의 전달, 손절별 입력, 화면 왕복, 저장 정책 복원, API 오류 표시, 600px 화면, 순서 미확정 결과와 WIN/LOSS 청산 시각 보존을 확인했습니다.
- 증거: `검증결과/revision113/ui/web-tests.xml`, `frontend.json`, `confirm-atr.png`, `confirm-narrow.png`. 두 화면 이미지는 실제로 열어 배치와 잘림을 확인했습니다.
- 외부 요청을 차단하고 API를 대체한 화면 검증입니다. MT5·라이브 엔진·텔레그램을 시작하지 않았으며 실제 데이터 전체 백테스트나 최종 설치 EXE 검증을 대신하지 않습니다.

## 매뉴얼

`매뉴얼/편집원본/제작.py`와 배포에 포함되는 `모세_사용자_매뉴얼.pdf`를 갱신했습니다. 총 25쪽과 기존 목차·페이지 번호를 유지하고 Part2의 16·17·19쪽 본문에 가상진입·ATR 제한·손절, 올존 원패턴의 남은 유효기간, 일반 신호의 확인 대기, 순서 미확정의 통계 제외를 반영했습니다. 다른 장은 본문 비교로 동일함을 확인했습니다. 수정한 세 페이지를 렌더링하여 글자 잘림 없이 읽히는지 검수했습니다. 증거는 `검증결과/revision113/ui/manual`에 있습니다.
