# 수정본136 매뉴얼 정리

135에서 복사했고 프로그램 코드는 135와 같습니다. 매뉴얼과 배포 도구만 바뀌었습니다.

## 매뉴얼

- **사용자 매뉴얼(34쪽)**: 디자인을 새로 했습니다. 텔레그램 쉬운설명서(수정본127)를 텔레그램 알림 장(7~15쪽)에 합쳤고, 따로 있던 PDF는 지웠습니다. 132~135 변경 사항(엔진 처리 지연 표시, 라이브 우선, 백테스트를 뒤로 보내도 느려지지 않음)도 반영했습니다.
- **간단사용서(3쪽, 새로 만듦)**: 파트1 라이브 감시, 파트2 백테스트, 파트3 AI 전략연구 사용법을 한 쪽씩 담았습니다. 쪽마다 사용자 매뉴얼의 해당 쪽을 안내합니다.
- 만드는 방법은 `매뉴얼/편집안내.md`에 있습니다. `제작.py`를 먼저 실행하고 `간단사용서_제작.py`를 실행합니다.

## 배포 도구

설치본에 두 PDF가 함께 들어갑니다.

- `releasekit/manuals.py`: `MANUALS`에 사용자 매뉴얼과 간단사용서를 둡니다. 둘 다 필수입니다.
- `releasekit/builder.py`: 두 PDF를 복사하고, 설치 데이터와 ZIP에서 용량·SHA-256을 확인합니다. 보고서에 `quick_guide`를 추가했습니다.
- `releasekit/validation.py`: 설치 데이터의 필수 파일에 두 PDF를 넣었습니다.

둘 중 하나라도 없거나 PDF가 아니거나, 만드는 도중 바뀌면 배포를 멈춥니다. 설치기는 설치본의 파일을 모두 관리 파일로 기록하므로 고치지 않았습니다. 업데이트 때 간단사용서도 새 파일로 바뀝니다.

## 검증 (`검증결과/revision136`)

- `manual/pdf_checks.json`, `manual/quick_checks.json`: 쪽 넘침, 필수 문구, 깨진 글자, 절대 경로 검사를 통과했습니다.
- `release_check.json`: 135와 코드 비교, 배포 도구 시험 결과입니다.
  - 매뉴얼 관련 시험 61개 통과.
  - 배포 도구 전체 447개 통과.
  - 회귀 시험 `test_quick_guide136.py` 7개: 설치본·보고서 포함, 없음·손상·ZIP 변조 시 중단, 현재 수정본에 두 PDF가 있는지 확인.
