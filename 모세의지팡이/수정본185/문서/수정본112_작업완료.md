# 수정본112 작업 완료

수정본111을 보존하고 수정본112에서 요청한 세 항목을 적용했습니다. 이전 검증결과와 배포 산출물, 다운로드·빌드 캐시는 복사하지 않았습니다.

1. 설정 화면 맨 아래에 `버전 112`를 표시합니다. 개발본은 수정본 폴더의 번호를 읽고, 배포는 빌드할 때 저장한 번호를 읽습니다. 이후 수정본113에서 배포를 만들면 113이 반영됩니다. 배포 폴더를 옮기거나 이름을 바꿔도 빌드한 버전은 유지합니다. 배포 도구에서 정하는 `v1.0` 같은 배포 이름과 구분합니다.
2. 스페셜 및 Part3 생성 전략 알림에서 `조건`, `트리거`, `등급` 줄을 제거했습니다. 문구를 구성하던 불필요한 코드도 삭제했습니다. 내부 판정과 신호 정보는 유지합니다.
3. 경제지표 이름을 `소비자물가지수(CPI)`처럼 표시합니다. 전월·전년·전분기 대비, GDP 발표 차수도 유지합니다. 알려진 약어가 없는 항목에는 임의 약어를 만들지 않습니다. 미등록 지표는 원문을 유지합니다.

## 검증

- 알림 등록·출력 경계: 32개 테스트 통과. 기존 스페셜 7개와 실제 Part3 컴파일러가 만든 전략의 매수·매도 알림, 조건 불충족 차단, 개인 WATCH 유지 확인.
- 경제지표: 44개 테스트 통과. 한글명·기준 기간·발표 차수·시간대·대상 필터·중복 방지 확인.
- 버전 표시와 기존 배포 구성: 39개 테스트 통과. 실제 설정 API와 브라우저의 최하단 표시, 다음 버전 반영 확인.
- 통합 배포 구성: 8개 테스트 통과. 현재 배포 파일 선택·코드 번들 생성 경로를 사용해 개발본과 소스 코드 없는 배포의 알림·경제지표·설정 API·웹 자산이 동일한지 확인. 배포 폴더를 옮긴 뒤에도 112 유지.
- LIVE/Part2 재생: 1개 테스트 및 3개 하위 사례 통과. 같은 합성 Wire 입력에서 최종 알림과 전략 상태 일치.

총 124개 테스트와 3개 하위 사례가 통과했습니다. 실제 텔레그램 메시지는 보내지 않았습니다. 최종 통합설치 EXE는 이번 작업에서 생성하지 않았으며, 수정본112의 `모세의지팡이 배포.cmd`로 만들 수 있습니다. 배포 확인은 Python 원본 없이 실행하는 코드 번들과 현재 웹 자산을 대상으로 수행했습니다.
