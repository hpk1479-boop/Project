# 수정본68 — 전략 연구 이름과 설정 화면 정리

수정본67을 복사해 작업했다. 이전 검증결과·캐시는 복사하지 않았다.

## 화면 변경

Part3 메뉴, AI 화면 제목, 시작 로그, 설정 설명의 “전략 생성”을 “전략 연구”로 변경했다. 전략 파일 생성 버튼의 실제 동작과 내부 API·식별자는 유지했다.

기존 Config 기반 라이브 설정 37개를 기본 6개와 상세 31개로 분류했다. 기본에는 관심 종목과 텔레그램 연결·채팅방, 경제지표 알림 사용 여부를 표시한다. 상세에는 MT5·프로그램 연결, 감시 데이터·지표 기준, 거래 시간대, 라이브 명령 AI 보조 해석, 갱신 주기·알림 기록, 진단·로그를 묶었다. 현재 목록에 없는 추가 키는 기타 상세 설정으로 표시한다.

상세 설정은 native details/summary로 펼친다. 처음 로드, 설정 화면 재진입, 재조회와 저장 후에는 접힌 상태다. 사용자에게 필요한 경우 직접 펼칠 수 있다. 상세 설정 안의 입력도 기존 저장 컨테이너에 두어 기본·상세 값을 같은 저장 버튼으로 저장한다. 비밀값은 기존대로 숨기며, 빈 입력은 유지하고 명시한 삭제만 반영한다.

현재 없는 MT5 실행파일 경로 등 새 설정은 추가하지 않았다. Part1·Part2, Config 파일, Part3 저장·검증 API, AI·Recipe·백테스트 동작은 수정하지 않았다.

## 검증과 증거

공식 검사에 `verification/test_settings_layout68.py`를 추가했다. 기존 메뉴 검사의 표시 문자열만 새 이름으로 바꿨다. 실제 웹 JavaScript로 설정 그룹·필드 보존, 상세 접힘·재진입·재조회, 숨겨진 입력 저장, 비밀값 유지·삭제·교체, 오류와 도움말 연결을 검사한다.

실제 Chrome 합성 화면에서 37개 항목 보존, 기본 6개·상세 31개 분류, 접힌 입력 저장, 재진입 시 접힘, JavaScript 오류 0과 390px 너비의 가로 넘침 0을 확인했다. 실제 사용자 설정은 저장하지 않았다.

전체 공식 검사 집계는 `CURRENT_VERIFY.md`와 `검증결과/current_verify/latest.json`, 화면 증거는 `검증결과/설정화면68`, 수정 범위 증거는 `검증결과/작업범위68.json`에 기록한다. 새 증거는 이 수정본에서 생성한 것만 보관한다.
