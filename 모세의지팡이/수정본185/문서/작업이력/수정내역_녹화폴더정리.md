# 녹화 데이터 폴더 정리

## 변경

- 창고의 녹화 조각은 `captures/종목/녹화방식/연도/월/조각ID_세대ID/`에 둔다. 예: `captures/XAUUSD+/BAR/2025/09/…/`. BAR와 TIMER, XAU와 BTC가 폴더에서 구분된다.
- 새 녹화와 기존 MSP3 변환 모두 처음부터 이 위치에 저장한다. 경로 구성 시 종목·녹화 방식·시작일을 검증한다.
- 현재 창고에 등록된 조각 **44개**를 같은 구조로 이동하고 `captures.duckdb`의 `path` 열과 metadata JSON의 상대 경로를 함께 갱신했다. 파일 내용과 capture_id는 바꾸지 않았다. 이동 전·후 경로 목록은 `검증결과/capture_layout/migration.json`에 창고 상대 경로로 기록했다.
- 과거 실행 결과와 사용자 설정은 그대로 두었다. 새 녹화나 MT5 실행은 하지 않았다.

## 검증

- 이동한 44개 조각의 파일 해시가 카탈로그와 모두 일치한다. XAUUSD+와 BTCUSD 조각이 새 구조에 있으며, `captures` 바로 아래의 이전 평면 조각 폴더는 없다.
- XAUUSD+ 2026-09-01 BAR: 이동 뒤에도 기존 조각 1개 재사용, 새 녹화 0개. 실제 재생에서 **1,378묶음**을 처리했다. 이동 전·후 SPECIAL1 알림은 **각 1건으로 내용과 순서가 같다**. 실행 ID와 결과는 `검증결과/capture_layout/replay_verification.json`에 기록했다. 실제 텔레그램 전송은 없다.
- 새 조각의 폴더 경로, 평면 조각 이전·재실행 멱등성, 창고 전체를 다른 위치로 옮긴 뒤 카탈로그 조회, 새 녹화 경로 연결을 확인하는 회귀 시험 **3개 통과**. 관련 EA 빌드 호환성 회귀 시험 **5개 통과**.
