# 수정본108 라이브 감시 하단 상태 표시

현재 수정본108에서 하단 상태 표시만 정리했다. 기존 여덟 모듈 카드와 라이브 엔진 동작, 백테스트, MT5 코드는 변경하지 않았다.

- 평소에는 라이브 감시 연결중·연결대기·상태 확인 대기 또는 오류 안내 중 하나를 표시한다.
- 시작·종료 완료 안내는 3초 후 사라진다. 완료 안내가 표시되는 동안 평소 상태 문구는 숨겨 중복 표시를 없앴다.
- 진행 중 안내와 오류·경고는 자동으로 지우지 않는다. 새 안내가 나오면 이전 완료 안내의 타이머를 취소한다.
- 내부 실행 파일 경로와 상세 결과는 메인 하단에 표시하지 않는다. 전체 로그와 EVENT 로그에서 `[라이브 제어]` 기록으로 확인할 수 있다. 이 기록은 현재 화면 세션의 최근 30개 결과를 보관하며 다른 모듈 로그에는 섞지 않는다.
- 원래 로그 일시정지 동작을 유지한다. 전략 설정 저장과 초기 상태 조회 실패에서도 내부 원문이 하단에 남지 않게 정리했다.
- 창 종료 중에 늦게 도착한 시작·종료 응답은 로그에만 기록하고 종료 진행 안내를 덮지 않는다. 재시작 확인 응답도 종료 중에는 확인 대화를 열지 않는다.

제품 변경은 `Part3/web/unified.js`, `Part3/web/style.css` 두 파일이다. 기존 재시작 회귀 시험은 짧은 안내와 상세 로그의 새 표시 위치를 검사하도록 갱신하고, 새 실제 브라우저 시험을 추가했다.

기존 시작·종료·전략 설정·텔레그램 화면과 실제 소스 없는 배포 포함 검사 58개 및 하위 검사 18개가 통과했다. 독립 검토에서 발견한 창 종료 안내 경합을 보완한 뒤 관련 제어·배포 검사 42개를 다시 통과했다. 새 실제 Edge 화면 검사는 창 종료 경합 3개를 포함하여 21개 모두 통과했고 JavaScript 오류는 없다. 2999/3000ms 경계, 새 메시지의 이전 타이머 취소, 초기·주기 상태 조회 오류, 저장 후 상태 복귀, 기록 보존·일시정지·다른 모듈과 분리, 기존 카드·재시작 요청 의미를 확인했다. 일반·완료·오류·좁은 화면·창 종료 중 렌더링도 확인했다. Part1·Part2 보호 대상 파일 1,777개도 변경이 없음을 확인했다.

검증은 가짜 API와 임시 배포 폴더를 사용했다. 실제 라이브 엔진·MT5·텔레그램 메시지는 실행하지 않았다. 새 증거는 `검증결과/live_status108`에 기록했다.
