# 수정본69 — 종료 화면과 전략 설정 팝업

수정본68을 복사해 작업했다. 이전 검증결과와 캐시를 복사하지 않았고, 수정본60의 GUI는 배치와 조작 방식만 참고했다. Part1·Part2 계산 로직, AI/schema/Recipe/validator/compiler, 기존 사용자 설정은 수정하지 않았다.

## 전체 종료와 창 닫기

- 전체 종료를 누르면 기존 Part1 라이브 엔진 종료 API를 호출하고 현재 화면을 유지한다. 종료 안내를 하단 상태줄 안으로 옮겼다. 안내가 별도 grid 행을 차지해 모듈 카드 영역을 압축하던 문제가 사라진다.
- START_MOSES 전용 창에서 X를 누르면 제목과 하단에 기록 저장·엔진 종료 확인 중이라는 안내가 나온다. 종료 확인 동안 시작/종료 버튼을 잠그고, 완료하면 창을 닫는다. 종료 요청을 중복 실행하지 않는다.
- 종료 확인 실패 시 창을 유지하고 다시 시도할 수 있게 안내와 버튼을 복구한다. UI 안내 자체의 실패·지연은 엔진 종료를 막지 않는다.
- 기존 정상 종료·저장 확인·제한 시간·강제 종료 정책은 그대로다. 엔진 상태를 새로 확인하므로 앞선 전체 종료 성공만으로 확인을 생략하지 않는다. X 클릭 이후의 실제 엔진 종료 시간을 줄였다고 주장하는 변경은 아니다.

## 전략 설정

Part1·Part2 전략 설정을 전용 팝업으로 표시한다. 기존 GUI의 2열 전략 카드, 사용 체크, OZ 프로필 선택, 거래시간 설정, 하단 저장/취소 배치를 웹 디자인에 맞췄다. 좁은 화면에서는 1열로 바뀐다. Part1에는 라이브 연결 상태도 표시한다.

- OZ 프로필과 거래시간은 작은 추가 팝업에서 편집한다. 설정을 열 때 초안을 만들고 저장/적용 때만 반영한다. 자식 팝업 취소는 해당 편집을, 부모 팝업 취소는 전체 초안을 버린다.
- Part1 저장은 기존 SPECIAL 설정 저장 API를 사용한다. 저장만으로 엔진을 시작하지 않는다. 설정은 다음 엔진 시작 시 적용된다.
- Part2 적용은 현재 백테스트 요청의 전략 설정만 변경한다. Part1 설정을 저장하거나 Part2 엔진 계산을 바꾸지 않는다.
- 설정 조회 실패·저장 실패·손상 설정 복구 확인·시간 형식 검사·기본값 복원 흐름을 유지한다. 라이브 상태 갱신으로 사용자의 편집 초안을 덮어쓰지 않는다.

## 읽기용 API 필드

기존 라이브 전략 목록 및 백테스트 옵션 응답에 `session_labels`, `session_times`, `default_time_filters`를 추가했다. 라이브 각 전략에도 기존 소스에서 읽은 `default_time_filters`를 제공한다.

Part1이 이미 제공하는 세션 목록과 소스 기본값 읽기 함수를 사용한다. 기존 Config에서 요청한 세션 시간만 읽고 텔레그램 등 다른 설정을 전달하지 않는다. 실제 계약인 `MAIN_ASIA`·`MAIN_LONDON`·`MAIN_NEWYORK`를 UI와 저장 요청에 그대로 사용한다. 배열 형태의 기본 활성 세션과 시각 맵을 구분해, 기본값을 그대로 저장해도 활성 세션이 보존되고 불필요한 시각 덮어쓰기가 생기지 않는다. Part1 소스 파일 수정이나 새로운 시간 판단·지표 계산은 없다.

변경 제품 파일은 `Part3/web/index.html`, `unified.js`, `style.css`, `Part3/lab/desktop_window.py`, `unified_live.py`, `unified_backtest.py`, `unified_settings.py`다. 범위 비교는 `검증결과/작업범위69.json`에 기록한다.

## 검증

`python verify_current.py` 종료코드 0: Part1 1057, Part2 379, Part3 451, Python 288, JS 6, Verifier 10, 합계 2191 PASS / 0 FAIL / 739 SKIP. 기존 제외 목록과 이유는 유지했고 결과 마지막 및 summary에 표시한다.

신규 회귀는 팝업 21건, 읽기 메타데이터 4건, 창 닫기 안내 5건이다. 저장/취소와 기존 세션 보존, 배열·부분 배열·빈 배열·0·시각 맵·단일 세션 기본값, 손상 설정 복구, 폴더 이동, 느린 종료 중 안내와 중복 요청, 안내 오류, 종료 실패 후 재시도를 검사했다. 기존 `Part3/tests/test_settings_korean59.cjs`의 거래시간 fixture도 실제 `MAIN_*` 계약으로 바로잡았다.

실제 Chrome 화면 검사 18개 PASS, JS 오류 0, 외부 네트워크 요청 0. 1440·2086·390px에서 종료 후 배치와 팝업, 거래시간 및 프로필 편집을 확인했다. 실제 배열 기본값의 무수정 저장·재열기에서 세션 보존도 확인했다. 합성 API를 사용했으며 실제 사용자 설정, 엔진, MT5, Ollama는 호출하지 않았다. 실제 MT5 및 전용 창의 종료 소요 시간은 이번 검사에서 측정하지 않았다.
