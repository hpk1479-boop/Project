# 수정본64 — 공식 연결 API와 대시보드 병합

문서 정리가 끝난 수정본63을 복사하고 수정본62의 공식 연결 API 변경을 병합했다. 수정본62·63은 수정하지 않았고 이전 검증결과와 캐시는 복사하지 않았다. 수정본63 보고서의 “62 미포함” 설명은 작성 당시 상태이며 수정본64에는 아래 변경이 포함된다.

## 병합 범위

병합 대상 코드 6개는 수정본63과 수정본61이 같았다. 수정본64에서 해당 파일만 수정본62의 구현으로 교체했다. 대시보드 변경 파일과 겹치는 부분은 없었다.

| 파일 | 병합한 기능 |
|---|---|
| `Part1/program/event_composer_domain.py` | 구독 provider, 검증된 Fact observer, OZ handler 등록 범위, 공유 리소스·시장 문맥·기존 Output 연결 API |
| `Part1/program/event_engine/board.py` | 읽기 전용 `publication_token` |
| `Part1/program/event_application.py` | 외부 전략의 공식 loader 등록·해제 |
| `Part3/lab/intent_port.py` | 구독/Fact private 메서드 교체와 private 데이터 접근을 공개 API로 연결 |
| `Part3/lab/ai_compiler.py` | 생성 전략의 상속 OZ handler 연결을 공개 등록 API로 변경 |
| `Part3/backtest.py` | 호스트 loader 교체를 `register_strategy_loader(...)`로 변경 |

세부 API 계약과 제거한 private 접근은 [수정본62 작업 기록](수정내역_Part3공식연결API62.md)에 있다. 전략 조건과 Recipe 변환·검증·컴파일 의미는 유지했고 생성 코드의 연결 부분만 기존 62 변경을 적용했다. 저장된 생성 전략 파일은 그대로 유지했다.

## 유지한 내용

- 수정본63의 결과/analytics 조회 API, 원본 다운로드, 카드·차트·상세 탭과 반응형 UI.
- 수정본63의 문서 폴더 정리, 중복 참조 문서 제거 및 참조 목록.
- Part1의 실제 전략·Fact·OZ 계산 로직과 Part2 전체.
- 기존 schema, Recipe v2, validator, execution plan과 기존 테스트 파일.
