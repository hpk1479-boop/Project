## 동작

`START_MOSES.pyw`로 연 웹 전용 창의 닫기 버튼을 누르면 실행 중인 Part1 라이브 이벤트 엔진을 다른 수정본까지 포함해 종료한다. 각 엔진의 자식 프로세스도 종료한다. 다시 조회해 엔진이 남지 않았음을 확인한 뒤 창과 localhost UI 서버를 닫는다.

종료는 별도 스레드에서 처리한다. 반복해서 닫기를 눌러도 종료 작업을 중복 실행하지 않는다. 조회 실패·권한 문제·종료 후 잔존 엔진은 실패로 처리하고 오류를 표시하며 창을 유지한다. 다시 닫기를 눌러 재시도할 수 있다. 종료 중 새 라이브 시작 요청은 받지 않는다. 이미 진행 중인 시작 요청이 있으면 끝난 뒤 종료 대상으로 확인한다.

현재 사용 중인 엔진 명령줄은 Python의 실행 스크립트가 `Part1/program/event_host.py`인 경우로 식별한다. 현재 수정본의 전체 경로로 검색 범위를 제한하지 않는다. 명령줄의 다른 인자나 `-c`·`-m` 코드에 같은 경로 문자열이 등장하는 경우, 백테스트와 무관한 Python 프로세스는 종료 대상으로 삼지 않는다. 종료 대상 프로세스 핸들을 유지하고 생성 시각을 확인해 PID가 다른 프로세스로 재사용된 경우를 구분한다. 루트의 절대 위치는 코드나 설정에 저장하지 않는다.
