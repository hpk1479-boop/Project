수정본87 — 종목 기본 선택과 Gemini 모델 선택 UI

수정본86을 복사해 작업했다. 이전 검증결과는 복사하지 않았다.

변경 내용
1. 백테스트 종목 선택의 빈 옵션 제거. captures 폴더의 실제 종목명만 유지한다.
2. 최초 종목 선택은 골드(XAU/GOLD 계열), 없으면 나스닥(USTEC/NAS100/NASDAQ/US100/NDX 계열), 둘 다 없으면 기존 목록 첫 종목이다. 이름을 변환하거나 새 종목을 추가하지 않는다. 사용자가 선택하거나 직접 수정한 값은 화면 복귀/목록 갱신 시 유지한다.
3. 설정창의 선택 드롭다운에 백테스트와 동일한 ▼ 아이콘을 사용하고 중앙 정렬한다. 설정 항목·접힘 상태·저장 동작은 유지한다.
4. Gemini 모델은 한 입력칸에서 문자 부분을 클릭해 직접 수정하고 오른쪽 화살표로 목록을 선택한다. Google models.list에서 generateContent 지원 모델의 실제 ID만 표시한다. 표시용 이름이나 모델 버전을 하드코딩하지 않는다.
5. 등록된 키 또는 저장 전 새 키로 모델 목록을 읽는다. 키 미등록/조회 실패 시 직접 입력은 계속 가능하다. 목록 조회는 키를 저장하지 않으며 전략/Recipe/소스코드를 전송하지 않는다.
