# 수정본58 — AI 전략 생성 영역 확대

2026-10-01. 수정본57을 복사해 수정본58에서 작업했다. 이전 검증결과 폴더와 Python/pytest 캐시는 복사하지 않았다.

## 변경

- Part3 전략 생성 메인 화면의 ‘최근 생성한 전략’ 카드와 목록을 제거했다.
- 제거한 목록을 초기화하거나 생성 후 갱신하던 JavaScript 호출을 제거해, 없는 요소에 접근하면서 화면 초기화나 생성 완료 처리가 실패하지 않게 했다.
- 오른쪽 전략 미리보기의 최대 폭을 390px에서 330px로 줄여 AI 영역의 가로 공간을 60px 늘렸다. 목록이 차지하던 세로 공간도 AI 영역에 배정했다.
- AI 패널 최소 높이는 310px에서 420px, 대화 영역 최소 높이는 180px에서 240px, 입력창 최소 높이는 86px에서 110px로 늘렸다.
- 작은 창에서는 기존처럼 미리보기가 AI 영역 아래에 배치된다.

제품 코드 변경은 `Part3/web/index.html`, `Part3/web/app.js`, `Part3/web/style.css` 3개다. 회귀 시험 `Part3/tests/test_strategy_layout58.cjs` 1개를 추가했다.

기존 생성 파일은 삭제하지 않았다. ‘생성한 Test 전략 백테스트’에서 전략을 선택하는 목록 조회는 유지했다. Part1·Part2와 Part3 백엔드 전체 파일이 수정본57과 동일함을 확인했다. AI 모델 설정과 웹 창 닫기 시 엔진 종료 기능도 그대로 복사됐다.

## 검증

관련 시험 23개 통과: 격리된 Edge의 UI 시험 8개와 기존 통합 웹 시험 15개. JavaScript 구문 검사도 통과했다.

UI 시험은 실제 HTML/CSS/JS를 사용하고 API 응답만 대체했다. 목록 제거 후 초기화, 1440×900·1280×800·900×800 배치, AI 입력과 응답, 해석 적용·미리보기·생성 완료, 백테스트 전략 선택 목록, 화면 이동 후 대화 유지가 정상인지 확인했다. 전략 파일 생성이나 실제 AI 추론·엔진 실행은 하지 않았다.

1440×900에서 AI 패널은 1062×664px, 대화 영역은 약 1024×400px이다. 1280×800에서는 AI 패널 902×564px, 대화 영역 약 864×300px이다. 세 창 크기 모두 가로 넘침 없이 표시됐다. 화면 캡처를 확인했다.
