# 데이터 구축 실패 원인 및 안내 수정

수정본54 전체를 수정본55로 복사했다. 이전 검증결과 폴더는 복사하지 않았다. 이전 수정본은 수정하지 않았다.

## 확인한 원인

- 창고 `runs/5fcfe837032145439ecdfb585dcc3220/progress.jsonl`의 2025-08 구축 시도는 두 번 모두 시작 전에 종료됐다.
- MT5의 2026-10-01 02:28 저널에는 ICMarketsSC-Demo 연결과 `symbol XAUUSD+ not exist`가 기록돼 있다.
- 종료 코드는 unsigned `3294954938`, signed `-1000012358`이며, MT5 저널은 이를 `tester symbol does not exist`로 설명한다.
- 이 종목이 없는 서버로 로그인한 것이 해당 실행의 실패 원인이다. 기존의 “이미 켜진 MT5가 있는지 확인하세요”는 실제 원인과 다른 일반 안내였다.
- 이후 MonetaMarkets-Demo로 바뀐 기존 실행 `runs/5bbf5dbbe2bb48f18cadd030b37ed378/progress.jsonl`에서 XAUUSD+ 녹화 시작·추출·차분 변환 진행을 확인했다. 이는 기존 실행 관측이며 수정본55로 새 녹화를 실행한 결과는 아니다.

## 변경

- `Part2/generic_backtest/native_mt5.py`: EA 시작 전의 위 종료 코드를 별도 종목 없음 오류로 구분한다. 선택 종목과 현재 서버를 표시하고, 해당 종목을 제공하는 계정·서버 또는 기존 브로커 종목 설정을 확인하도록 안내한다.
- 종목 없음 오류는 일시적 시작 실패로 분류하지 않으므로 동일 계정으로 무의미한 1회 재시도를 하지 않는다.
- 일반적인 일시적 테스터 시작 실패의 기존 1회 재시도는 유지한다.
- `tests/test_tester_start55.py`: 종목 없음 코드의 signed/unsigned 처리, 요청 파일 정리, 화면 오류 전달, 일시적 실패 재시도, 재시도 상한, 터미널 사용 중 차단, 정상 완료 계약을 확인하는 표준 라이브러리 시험을 추가했다.

전략 판정, EA, Wire, 녹화 저장 형식, 계정 설정, 기존 녹화 데이터는 변경하지 않았다. 진행 중인 데이터 구축과 MT5 프로세스도 중단하지 않았다. Part1 변경은 없다.

## 이미 완료한 확인 및 종료

사용자의 시험 중단 지시 전에 신규 시험 5개가 통과했다. 실제 MT5·네트워크 호출은 시험에서 차단했다. pytest가 없어 기존 pytest 회귀 묶음은 실행하지 못했다. 이후 추가 시험·실측·녹화 없이 작업을 종료했다.

실제 새 구축의 완료 검증은 하지 않았다. 이 수정은 종목·서버 불일치 원인을 정확히 안내하는 것으로, 계정이나 종목을 자동으로 교체하지 않는다.
