# 수정본125 알림 채널 없이 개인채팅으로 알림 받기

수정본124를 그대로 복사해(검증결과 제외) 수정본125를 만들었습니다. 알림 채널·그룹(`TELEGRAM_CHAT_ID`) 없이 혼자 쓰는 경우에도, 개인채팅 알림 설정을 켜면 라이브 알림과 경제지표 알림을 1:1 개인채팅에서 받게 했습니다.

## 혼자 쓰는 경우 설정

| 설정 | 값 |
|---|---|
| `TELEGRAM_CHAT_ID` (알림을 받을 채팅방) | 비워 둠 |
| `TELEGRAM_COMMAND_CHAT_IDS` (명령을 보낼 수 있는 채팅방) | 내 1:1 채팅방 번호 |
| `PRIVATE_LIVE_ALERTS_ENABLED` (개인채팅 라이브 알림) | `true` (받기) |
| `PRIVATE_ECONOMY_ALERTS_ENABLED` (개인채팅 경제지표 알림) | `true` (받기) |

이렇게 하면 라이브 알림, 경제지표 알림, 내가 건 WATCH 알림이 모두 1:1 개인채팅으로 옵니다. WATCH 알림과 명령 답장은 원래 명령한 채팅방으로 갑니다.

## 바뀐 동작 (알림 채널이 없을 때만)

| 알림 | 수정본124 | 수정본125 |
|---|---|---|
| 라이브 알림 (전략 알림 등), 개인채팅 라이브 알림 켬 | 보낼 곳이 없다고 보고 만들지 않음 → 아무 데도 안 옴 | **개인채팅으로 옴** |
| 경제지표 알림, 개인채팅 경제지표 알림 켬 | 전송 실패, 확인 때마다 25초 대기 후 다시 시도 | **개인채팅으로 옴** |
| 위 설정을 끈 경우 | 아무 데도 안 옴 | 같음 (그대로) |
| 내 명령 답장, 내가 건 WATCH 알림 | 정상 | 같음 |

알림 채널이 있을 때는 수정본124와 똑같습니다. 백테스트는 항상 가짜 채널(`BACKTEST`)을 쓰므로 영향이 없습니다(시험으로 확인).

## 시험

- 채널 없음 + 라이브 켬: 개인채팅(1:1만, 목록의 그룹 제외)으로 전송, 빈 받는 사람 실패 기록 없음.
- 채널 없음 + 둘 다 끔: 지금처럼 아무 데도 보내지 않음.
- 채널 없음: 라이브 설정은 라이브 알림만, 경제지표 설정은 경제지표 알림만.
- 채널 없음: 한 채팅방으로 가는 답장은 그 채팅방에만.
- 채널 있음: 수정본124와 같음.
- 알림을 만드는 곳: 채널 없음 + 끔이면 만들지 않음, 켬이면 만듦. 채널이 있거나 받는 사람이 정해진 알림은 그대로.
- 실제 엔진(SPECIAL2, 라이브 모드): 채널 없음 + 켬이면 알림 1건이 만들어져 개인채팅 두 곳으로 감, 끔이면 0건.
- 백테스트 모드: 개인채팅 설정과 관계없이 알림이 같음(받는 사람 `BACKTEST`).
- 경제지표 전송 확인: 채널 없음 + 켬, 채널만, 채널 + 켬 모두 성공으로 끝나고 받는 곳이 맞음.
