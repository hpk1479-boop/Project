# 수정본113 — 공통 가상진입

수정본112를 보존하고 수정본113에서 작업했습니다. 기존 전략의 알림 판단과 MT5 EA·지표는 변경하지 않았습니다. 알림 이후의 가상진입을 한 가지 공통 설정과 엔진으로 처리합니다.

## 진입과 손절

- 즉시 진입: 알림 당시 가격으로 진입합니다.
- 확인 진입: 매수는 직전 확정봉 양봉, 매도는 음봉을 확인하고 현재 봉 시가로 진입합니다. 조건을 추가하지 않으면 봉 방향만 확인합니다.
- 추가 조건: 선택한 이평 위·아래, 이평 종가 돌파, 이평 터치 후 다음 봉 확인, 인걸핑, 해당 올존의 넥라인 종가 돌파입니다. 추가한 조건을 모두 충족해야 합니다.
- 이평 종류·기간·프레임을 선택합니다. 기존 6헐 전용 진입·6/17 역교차 취소 경로는 제거했습니다. 올존의 자동 기본값은 공통 조건의 HMA6 위·아래 확인 진입이며, 일반 신호의 자동 기본값은 즉시 진입입니다.
- ATR 제한: 확인봉 몸통 또는 고가·저가 폭, 현재 진입 가격과 선택한 이평의 거리입니다. 최소 배수 이상, 최대 배수 미만을 허용합니다. ATR 기간·프레임을 선택할 수 있습니다.
- 손절: 올존 B0, 직전 N개 확정봉의 저점·고점, ATR 배수를 선택합니다. 자동은 올존 B0 / 일반 신호 ATR 1배입니다.
- 신호 프레임 자동은 실제 성립한 일반 전략 조건의 가장 낮은 프레임, 올존은 실제 올존 발생 프레임입니다. ANY 선택·ALL 요구·SOURCE 참조·별도 가격 프레임을 보존하며, 명시적으로 다른 프레임을 선택할 수 있습니다.
- 손익비는 기존 1:1부터 1:5까지 0.5 간격의 9개 결과를 유지합니다.

## 올존의 유효기간

올존 알림 당시 원래 후보의 TRUE B0·교차 기준 타이머에 남은 실제 봉 수를 보존합니다. 더 짧은 제한을 따르며, 마지막 허용 봉까지 진입할 수 있고 그 다음 봉부터 대기를 종료합니다. 주말처럼 봉이 생기지 않는 시간을 임의로 봉 수에 포함하지 않습니다. 진입한 거래의 청산은 알림의 유효기간과 별개입니다.

원비 터치처럼 자체 유효기간이 없는 일반 신호에 올존의 만료 제한을 적용하지 않습니다. 확인 진입을 직접 선택한 일반 신호는 조건 충족 또는 백테스트 구간 종료까지 기다립니다.

실제 최종 신호만 진입 대상입니다. 감시 등록·중간 진행·취소 안내는 제외합니다. 완료 신호의 전달을 재시도할 때는 완료 당시의 가격·프레임·유효기간을 보존합니다. 다른 부모 알림의 B0·유효기간을 상속하지 않습니다.

생성 전략에서 마지막 완료 사건이 올존이면 원래 올존의 기간을 보존합니다. 앞선 올존 이후 일반 조건이 새로운 완료 사건이 되면 일반 신호로 처리합니다. 복합 조건이 나중에 완성되면 실제 최종 알림의 현재 시각·가격으로 진입하며, 과거 올존 가격으로 거래를 되돌리지 않습니다.

넥라인은 해당 알림의 실제 B0부터 오른쪽 알림 봉 사이의 확정봉에서 매수 고점 / 매도 저점을 고정합니다. 과거의 다른 패턴이나 이후 형성되는 봉으로 바꾸지 않습니다. 넥라인 자료가 없는 경우 값을 추측하지 않고 안내합니다.

## 결과와 배포

봉 중간에 즉시 진입한 첫 1분봉에서 손절·목표가 접촉했지만 접촉 시점이 진입 전후 어느 쪽인지 알 수 없다면 해당 손익비의 결과는 ‘순서 미확정’입니다. 이후 봉으로 승패를 추정하지 않으며 승률·R 계산에서 제외합니다. 접촉하지 않은 손익비는 이후 봉에서 정상 평가합니다.

수동 백테스트, AI 확인 계획, 생성 전략 백테스트가 동일한 공통 계약을 전달합니다. 자연어 특정 문장용 우회 경로를 추가하지 않았습니다. 실행한 가상진입 정책만 저장하고 기존 전략 설정은 덮어쓰지 않습니다.

배포 코드·웹 자산이 실제 배포 선택 목록에 포함되는지, Python 소스가 없는 코드 묶음과 설치 폴더를 옮긴 상태에서 같은 계약·결과를 사용하는지 검증합니다. 배포만들기는 이 수정본의 최신 코드와 매뉴얼을 사용합니다. 이번 작업에서 최종 통합설치 EXE는 생성하지 않았습니다.

기존 시장 데이터 녹화는 그대로 사용합니다. 이전 알림 결과 CSV는 창고에서 읽을 수 있지만, 새 가상진입에 필요한 신호 종류·원래 유효기간·알림 가격이 빠져 있다면 알림 결과를 다시 생성해야 합니다. 부족한 자료를 추측해서 거래로 만들지 않습니다.

## 최종 확인

- 선택한 엔진·알림 전달·생성 전략·AI·수동 실행·취소·LIVE/재생 회귀검사 575개 통과.
- 실제 배포 선택 목록을 사용한 소스 없는 코드 묶음 검사 1개 통과. 개발본·배포 코드·이동한 배포 폴더의 계약과 결과가 같으며, 최신 웹 자산과 매뉴얼도 같은 파일입니다.
- 실제 Edge 수동 화면 검사 11개와 AI 정책 화면 검사 5개 통과. 매뉴얼 25쪽을 유지하고 변경한 세 페이지를 렌더링해 확인했습니다.
- 원본 수정본112의 3,410개 파일과 MT5 EA·지표를 보존했습니다. 사용자 백테스트 설정도 원본과 같습니다.
- 오래된 `PIPELINE_7` 내부 레지스트리를 요구하는 E2 검사 1개는 최종 선택에서 제외했습니다. 수정본112에서도 같은 KeyError를 읽기 전용으로 재현했습니다. 해당 옛 구조를 복원하지 않았습니다.

실제 Telegram 발송·Gemini 호출·MT5 연결·36GB 전체 기간 실행은 이번 검증에 포함하지 않았습니다. 합성 입력, 실제 녹화 형식의 독자, 실제 Edge 화면, 소스 없는 배포 코드로 필요한 경계와 전달을 확인합니다.
