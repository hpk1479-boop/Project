# 수정본166: 배포본 스페셜 폴더 — `스페셜/기본` · `스페셜/내 전략`

수정본165를 복사해 만들었고, 165의 검증결과 폴더는 복사하지 않았습니다. 개발본은 지금처럼 `Part1/program/SPECIAL`을 읽습니다. 설치본(배포본)만 설치 폴더 바로 아래 `스페셜`을 읽습니다. 배포·빌드는 하지 않았습니다.

## 사용자와 정한 것
- 개발본은 그대로 둡니다. 배포본만 스페셜 폴더를 위로 올립니다.
- 배포에 실려 오는 스페셜과 배포본에서 생긴 스페셜은 따로 보관합니다.
  - `스페셜/기본`: 배포에 포함된 전략입니다. 번호는 1~99이고, 업데이트가 교체합니다.
  - `스페셜/내 전략`: 설치 뒤 직접 만들었거나 클로드코드가 만들었거나 다른 사람에게 받은 전략입니다. 번호는 100~999이고, 업데이트가 건드리지 않습니다.

## 어디를 읽나

| 경우 | 읽는 폴더 | 번호 |
|---|---|---|
| 설치 폴더에 `스페셜`이 있음(설치본) | `스페셜/기본`, `스페셜/내 전략` | 기본 1~99, 내 전략 100~999 |
| `스페셜`이 없음(개발본) | `Part1/program/SPECIAL` | 1~999(전과 같음) |
| 둘 다 없음(옛 프로젝트) | `settings/strategy_registry.json` | 전과 같음 |

- 번호가 폴더와 맞지 않는 파일은 그 파일만 빠집니다. 알림 예시: `내 전략/SPECIAL5.recipe.json 제외 · 내 전략은 SPECIAL100~SPECIAL999만 씁니다`.
  - 다른 폴더에 같은 번호 전략이 있으면 그 전략은 그대로 돕니다.
  - 알림은 158에서 만든 경로를 그대로 씁니다(실시간 시작 결과, 전략 설정 화면, 엔진을 시작할 때 텔레그램 한 번).
- 한 폴더 안에 같은 번호 파일이 둘이면 둘 다 빠집니다(전과 같은 규칙).
- 하위 폴더를 지우면 빈 폴더로 읽습니다. `스페셜` 폴더가 있으면 옛 registry로 돌아가지 않습니다.
- `스페셜`이 설치 폴더 밖을 가리키면(정션 등) 읽지 않고 오류를 냅니다.
- 실시간(Part1), 백테스트(Part2), 전략연구소(Part3)는 모두 같은 읽기 함수(`strategy_recipe.special_files`)를 씁니다. 그래서 정의가 같습니다.
- 새 파일은 전략 목록을 다시 열면 보입니다. 실시간 감시에는 다음 실시간 시작부터 들어갑니다.

## 배포 꾸러미(빌드 도구)
- 개발본 `Part1/program/SPECIAL`의 `.recipe.json`은 그대로 `스페셜/기본`에 싣습니다.
- `.py` 스페셜은 그 안의 `PART3_RECIPE`를 `.recipe.json`으로 바꿔 싣습니다.
  - 전에는 코드 묶음에 컴파일해 넣었습니다. 이제 파이썬 파일은 싣지도 컴파일하지도 않습니다.
  - 읽히는 값은 같습니다. 설치본의 `기본` 폴더에는 데이터만 남습니다.
- 개발자용 `관리안내.md`는 싣지 않습니다. 대신 빈 `스페셜/내 전략` 폴더와 사용 안내 `스페셜/안내.md`를 넣습니다. 안내 원본은 `통합설치/releasekit/special_guide.md`입니다.
- `settings/strategy_registry.json`은 전처럼 개발본 폴더에서 만듭니다.
- 다음 경우에는 빌드를 멈춥니다.
  - 개발본 폴더에 100번 이상 파일이 있음
  - `.py` 스페셜을 읽지 못함(문법 오류, 같은 번호 중복)
  - 개발본에 `스페셜` 폴더가 있음

## 설치·업데이트(통합설치)
- `스페셜/내 전략/`은 사용자 파일로 보존합니다.
- 업데이트는 없어진 전략의 설정을 지웁니다(기존 동작). 이때 `내 전략`에 파일이 있는 번호의 설정은 남깁니다.
- 옛 설치본을 업데이트할 때:
  - 옛 `Part1/program/SPECIAL`에 배포로 깔린 파일(SPECIAL1~8, 관리안내.md)은 기존 규칙대로 지웁니다.
  - 받는 사람이 그 폴더에 넣어 둔 SPECIAL 파일은 `스페셜/내 전략`으로 옮깁니다. 같은 이름의 다른 파일이 이미 있으면 업데이트 전체를 되돌립니다.
  - 스페셜 파일이 아닌 파일은 그대로 둡니다.
- 이 PC의 배포본(136판)을 읽기만 해서 확인했습니다. 옛 폴더에는 배포 파일만 있어 업데이트해도 옮길 파일이 없습니다.

## 정할 것: 새 전략의 실시간 기본값
지금 규칙으로는 전략 설정에 없는 전략이 실시간에서 켜진 채 시작합니다(Part1 `start_live`, 기존 동작). 그래서 `내 전략`에 파일을 넣으면 다음 실시간 시작부터 그 전략 알림이 나갑니다. Part3에서 승급한 테스트 전략은 꺼진 채 시작하므로 이와 다릅니다.

Part1 규칙이라 바꾸지 않았고, `스페셜/안내.md`에 적었습니다. 클로드코드가 연구용으로 만든 전략이 바로 실시간으로 나가지 않게 하려면 둘 중 하나를 고르면 됩니다.
- (가) `내 전략`에 처음 들어온 전략은 꺼진 채 시작
- (나) 167 가져오기 기능이 꺼진 채 등록
