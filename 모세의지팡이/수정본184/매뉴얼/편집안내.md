# 모세 트레이딩 시스템 매뉴얼 관리

매뉴얼은 두 개입니다.

| 파일 | 내용 |
|---|---|
| **모세_사용자_매뉴얼.pdf** | 전체 설명서 49쪽(수정본175). 시작하기, 설치·MT5, 텔레그램 알림, AI 설정, 올존, 파트1·2·3, 설정 화면, 도움말 |
| **모세_간단사용서.pdf** | 파트1 라이브 감시·파트2 백테스트·파트3 AI 전략연구 사용법을 한 쪽씩 3쪽. 자세한 내용은 사용자 매뉴얼 쪽번호로 안내 |

수정본136에서 텔레그램 쉬운설명서(수정본127)를 사용자 매뉴얼의 텔레그램 알림 장(7~15쪽)에 합치고 따로 있던 PDF는 지웠습니다. 132~135 변경(엔진 처리 지연 표시, 라이브 우선, 백테스트를 뒤로 보내도 느려지지 않음)도 반영했습니다.

## 다시 만들기

1. `편집원본/제작.py`를 실행합니다. 사용자 매뉴얼을 만들고 장별 쪽번호를 `편집원본/쪽번호.json`에 적습니다.
2. `편집원본/간단사용서_제작.py`를 실행합니다. `쪽번호.json`을 읽어 "사용자 매뉴얼 N~M쪽" 안내를 넣으므로 반드시 1번 뒤에 실행합니다.

reportlab·pypdf가 있는 Python으로 실행하세요(기본 Python에 없으면 두 라이브러리가 있는 다른 Python). 스크립트는 자기 파일 위치를 기준으로 경로를 찾으므로 어느 수정본에서 실행해도 됩니다.

## 편집원본 구성

| 파일 | 역할 |
|---|---|
| `디자인.py` | 두 매뉴얼이 같이 쓰는 글꼴·색·장 색상·카드·단계·표·알림 상자·그림 |
| `제작.py` | 사용자 매뉴얼 문장. 장별 `add(...)` 안에 있음 |
| `간단사용서_제작.py` | 간단사용서 문장. 파트별 `part1`·`part2`·`part3` 목록 |
| `그림/` | 설정 화면 그림(set_*.png), 톱니바퀴·라이브 버튼 그림(tg_*.png)과 표지 아이콘(moses_icon.png) |

설정 화면 그림은 실제 화면 파일(`Part3/web`)을 Edge에 올리고 설명용 값을 넣어 찍습니다. 수정본175에서 `set_live_details.png`·`set_part2.png`를 이렇게 다시 찍었고, 도구는 `검증결과/revision175/tools/capture_settings175.cjs`입니다(Playwright 필요). 화면이 바뀌면 같은 방법으로 다시 찍으세요.
| `쪽번호.json` | 제작.py가 적는 장별 시작·끝 쪽 |

## 검사

만들 때 쪽 넘침, 필수 문구, 깨진 글자, 절대 경로가 들어갔는지 확인하고, 통과한 PDF만 기존 파일과 바꿉니다. 기록은 실행한 수정본의 `검증결과/revision<번호>/manual`에 남습니다(`pdf_checks.json`, `quick_checks.json`). 다시 만든 PDF는 글자가 잘리지 않았는지 화면에서도 확인하세요. 화면이나 기능이 바뀌면 문장과 쪽번호 안내를 함께 고친 뒤 두 파일을 다시 만드세요.

## 배포

1. 수정본 루트의 **모세의지팡이 배포.cmd**를 실행합니다.
2. 배포 설정을 정하고 **모세의지팡이 통합설치 만들기**를 누릅니다.

배포 도구는 실행한 수정본의 두 PDF(`매뉴얼/모세_사용자_매뉴얼.pdf`, `매뉴얼/모세_간단사용서.pdf`)를 읽어 설치본 `MOSES/매뉴얼/`에 넣고, 업데이트 때 새 PDF로 바꿉니다. 둘 중 하나라도 없거나 손상되면 배포를 멈추고, 원본과 배포 PDF의 용량·SHA-256과 통합설치 ZIP에 실제 들어간 내용을 검사합니다. 배포를 만드는 중에는 PDF를 고치거나 지우지 마세요.

편집원본과 이 안내서는 개발자 폴더에만 둡니다. 다음 수정본으로 옮길 때 이 매뉴얼 폴더와 통합설치 도구를 함께 복사하세요.
