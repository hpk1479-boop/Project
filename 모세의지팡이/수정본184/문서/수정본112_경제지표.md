# 수정본112 경제지표 알림

경제지표 이름을 `한글명(약어)` 형식으로 표시합니다. 비교 기간과 발표 차수도 유지합니다.

| 공급 캘린더 이름 | 알림 표시 |
|---|---|
| CPI m/m | 소비자물가지수(CPI) · 전월 대비 |
| CPI y/y | 소비자물가지수(CPI) · 전년 대비 |
| Core CPI m/m | 근원 소비자물가지수(Core CPI) · 전월 대비 |
| PPI m/m | 생산자물가지수(PPI) · 전월 대비 |
| Non-Farm Employment Change | 비농업 고용(NFP) |
| Advance GDP q/q | 국내총생산(GDP) · 속보치 · 전분기 대비 |
| FOMC Meeting Minutes | 연방공개시장위원회 회의록(FOMC) |
| Fed Chair Powell Speaks | 연방준비제도 의장(Fed) 파월 연설 |
| Unemployment Claims | 신규 실업수당 청구건수 |

약어가 없는 지표에는 새 약어를 만들지 않습니다. 소비·고용·PMI·연준 발표·연설 등 기존 알림 대상인 미국 주요 지표의 표준 이름을 보강했습니다.

아침 브리핑과 발표 전 알림이 같은 이름 변환 함수를 사용합니다. 예시는 실제 발표 일정을 뜻하지 않습니다.

```text
[주요 경제지표 및 연설 안내]

• 21:30
  - 소비자물가지수(CPI) · 전월 대비
  - 소비자물가지수(CPI) · 전년 대비
  - 근원 소비자물가지수(Core CPI) · 전월 대비
```

변경 파일은 `Part1/program/event_economy_host.py`입니다. 네트워크 요청, USD/High 필터, 한국 시간 변환, 발표 30분 전 알림 범위, 중복 방지용 원본 이벤트 ID, 전송 성공 후 기록하는 동작은 그대로 유지합니다. 기존 `EconomyWorker`와 선물 일정 함수가 변경되지 않았음을 AST 비교로 확인했습니다.

검증은 `tests/test_economy_titles112.py`의 44개 테스트가 통과했습니다. 기준 기간·GDP 발표 차수·한국 시간·USD/High 필터·동시 발표 묶음·전송 성공/실패 기록을 확인했습니다. 외부 캘린더 요청과 실제 텔레그램 발송은 테스트에서 차단했습니다. 증거는 `검증결과/revision112/economy/tests.xml`과 `summary.json`입니다.

공급 제목의 형식은 [현재 사용 중인 공식 공급 JSON](https://nfs.faireconomy.media/ff_calendar_thisweek.json)을 읽기만 하여 확인했습니다. 등록되지 않은 새로운 지표 이름은 의미를 임의로 바꾸지 않고 원문을 유지합니다. 알려지지 않은 연설자 이름은 철자를 유지하며, 역할과 연설·증언 표시는 한글로 표시합니다. 새로운 공급 이름까지 자동 번역하는 AI·서버 기능은 추가하지 않았습니다.
