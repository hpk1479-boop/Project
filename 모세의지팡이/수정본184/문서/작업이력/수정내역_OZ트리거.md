# 수정본3 · OZ(올리브오일 존) 트리거 조합 / 슈퍼 올존 / 전략설정 트리거 슬롯

기준: 원본 `Part1` (원본 폴더는 수정하지 않음). 이번 작업은 **Part1만** 수정했습니다.
Part2 백테스트 반영과 FVG·TREND·OZ monitor 최적화는 이번 범위에 넣지 않았습니다.

## 1. 새 OZ 프로필 (무지성·다이버전스·레짐·슈퍼 자유 조합)

| 수식어 | 의미 |
|---|---|
| 일반 | 중위 TF 밴드 OUT + 중위 TF HMA6 시가 조건 + 상위 TF 밴드 IN + 기본조건 (기존 NORMAL) |
| 무지성 | 중위·상위 조건 무시, 기본조건만 (기존 BLIND) |
| 다이버전스 | 최종 트리거를 B0 **엄격 돌파**만 허용 (기존과 동일, 변경 없음) |
| 레짐 | 상위 TF 레짐밴드 중심선 기울기·위치 (기존 레짐 필터와 동일) |
| 슈퍼 | 기준 TF 레짐밴드 중심선(Regime Basis) 다이버전스 (신규) |

- 순서는 자유입니다. `레짐 무지성 올존`과 `무지성 레짐 올존`은 같은 프로필입니다.
- 조합은 모두 16개입니다. 무지성과 레짐도 함께 쓸 수 있습니다. 이전에는 레짐을 고르면 일반으로 강제됐습니다.
- 공식 저장값은 `DIVERGENCE → REGIME → SUPER` 순서로 적습니다. 예: `REGIME_SUPER`.
- 기존 6개 프로필의 저장값과 알림 표시명은 그대로입니다.
- 표시는 `OZ` 또는 `올존`으로 합니다. Part1에는 원래 `ALLZONE` 표기가 없었고, 이번에 새로 넣은 코드도 모두 OZ/올존으로 적었습니다.

### 슈퍼 올존 판정 (Percentile family별)
- **매수**
  - 첫 번째 저점, 즉 그 family의 TRUE B0 봉에서 지표값이 Regime Basis **아래**여야 합니다.
  - 두 번째 알림 시점, 즉 현재 봉에서 지표값이 Regime Basis **위**여야 합니다.
- **매도**는 반대입니다. 첫 번째 고점에서는 **위**, 알림 시점에서는 **아래**여야 합니다.
- 지표값과 중심선 짝:
  - RSI: `RSI_val` ↔ `RSI_basis`
  - STO: `STO_val` ↔ `STO_basis`
  - DI: `DI_val` ↔ `DI_basis`
  - PRICE: `price_hma_6` ↔ `price_regime_basis`
- 레짐과 마찬가지로 실패해도 후보를 영구 무효화하지 않습니다. 그 시점의 필터 실패로만 처리합니다.

## 2. OZ 트리거 규칙 변경 (다이버전스를 뺀 모든 프로필)

- 근접(NEAR, ATR 10%)을 없애고 **터치만** 인정합니다. 터치는 현재 봉의 저가~고가 범위에 레벨이 들어오는 경우입니다.
- 동시조건이 아닙니다. **OZ 후보가 살아있는 동안 조건 충족을 누적**합니다. 누적 상태는 checkpoint에 저장되므로 재시작 후에도 이어집니다.
  1. TRUE B0 터치 → **즉시 통과**. MIN_BARS 이후에만 인정하므로, B0 봉 자신의 터치는 제외됩니다.
  2. HMA17(open) 터치
  3. 원비 터치 (매수는 하단, 매도는 상단)
  4. 매수: 하락장악 + 추가 음봉, 또는 3연속 음봉 / 매도: 반대
  5. HMA6 색 꺾임 (마감봉, 2개봉 전 기울기 기준: hull > hull[2] = 상승색)
     - 매수: 직전 마감봉 상승색 → 최근 마감봉 하락색 / 매도: 반대
  - 2~5번 중 **서로 다른 조건 2개 이상**이 누적 TRUE면 통과합니다.
- 5번은 수정본4에서 원래의 "HMA6 색 꺾임"(`_hma6_turn_pullback_trigger`, 원본과 동일 코드)으로 롤백했습니다. 수정본3의 "HMA6 시가 기울기" 판정은 삭제했습니다.
- 알림의 트리거 표시 예:
  - `B0`
  - `HMA17, HMA6 하방꺾임` (매도는 `HMA6 상방꺾임`)
- 만료와 탈락 규칙(TRUE B0 10봉, HMA 크로스 7봉, OUT→IN 7봉, 반대 크로스, 일방향 3봉)은 기존과 같습니다.
- 후보가 만료·탈락하면 누적도 함께 사라집니다. 등록된 Percentile family가 모두 만료된 경우에도 누적을 초기화합니다.

## 3. Watch

- Watch 문장에 `슈퍼`와 `일반`을 더 쓸 수 있습니다. 예:
  - `골드 1분 무지성 레짐 올존 알려줘`
  - `2분 슈퍼 올존 알려줘`
  - `5분 매수 슈퍼 레짐 올존 알려줘`
- 연쇄 Watch와 개인전략 요약 문구도 같은 표시명을 씁니다.

## 4. OZ_SYSTEM CONTROL [전략 설정] 트리거 슬롯

- SPECIAL마다 다음 세 가지가 있습니다.
  - **실행 체크박스**
  - **트리거 입력칸** (Watch처럼 적습니다. 예: `무지성 다이버전스 올존`)
  - **기본값 버튼**
- 기본값은 각 SPECIAL 코드의 `FINAL_VALIDATION_MODE` / `FINAL_TRIGGER_MODE`를 실행하지 않고 읽어서 채웁니다. 예:
  - SPECIAL1 = 다이버전스 올존
  - SPECIAL5 = 무지성 올존
  - SPECIAL7 = 다이버전스 레짐 올존
- [저장]
  - 저장하면 `Part1/special_settings.json`에 기록되고, 다음 실행 때 다시 불러옵니다.
  - 잘못된 문구가 있으면 오류를 띄우고 저장하지 않습니다.
  - 코드 기본값과 같은 조합이면 저장하지 않으므로 SPECIAL 코드 기본값을 계속 따릅니다.
- 적용 경로:
  1. 전략 설정
  2. [전체 시작]
  3. 환경변수 `OZ_SPECIAL_TRIGGERS`(JSON)
  4. `manager_KIM`이 `oz_profiles`에 등록
  5. 각 SPECIAL이 import 시점에 자기 최종 OZ 트리거를 확정
  - 따라서 LIVE 진입 조건, 알림 문구, 자식 Watch에 모두 같은 값이 적용됩니다.
- SPECIAL5는 **최종(하위) OZ**만 슬롯으로 바꿉니다. 상위 부모 Watch(다이버전스 / 다이버전스 레짐)는 그대로입니다.
- 설정은 manager_KIM이 시작될 때 적용됩니다. 실행 중에 바꿨다면 재시작해야 합니다.
