# 수정본58 — 한국어 AI 해석 화면과 설치 모델 선택

2026-10-01. 수정본58에서 이어서 작업했다. 이번 작업의 증거는 새 `검증결과/AI표시설정58/`에 저장했다.

## 해석 결과 화면

원본 canonical intent를 수정하지 않고 표시만 한국어로 바꿨다. 종목·방향·조건 관계·시간 제한·최종 행동·감시 모드를 요약하고 조건을 번호별로 구분한다. 원본 AI 응답 전체는 기본적으로 접힌 ‘상세 보기 · 원본 해석 / JSON’에 보존한다. 해석 적용과 생성 요청에는 원래 Recipe v2와 intent를 그대로 전달한다.

화면 예시:

- 종목: XAUUSD+ (현재 기본값)
- 방향: 매수
- 조건 1: 15분봉이 상승추세 · 확정봉 기준
- 조건 2: 3분봉 하단 WONBI 터치 · 판정 방향: 매수
- 조건 관계: 동시에 평가 · 모든 조건을 만족
- 시간 제한: 최종 감시 유효시간 10분
- 최종 행동: 1분봉 일반 브레이커 감시
- 감시 모드: 반복 감시

매수·매도, 일반·무지성, 올존·브레이커, 동시·순차·순서 무관 관계와 15개 조건 종류를 표시한다. 독립 분기, 선행 사건 후 조건, 최종 재확인 조건, 취소 조건, 지표/시간봉 결합, 확정봉/진행봉과 기반 전략 설정도 구분한다. FVG 영역 접촉을 ‘가격이 영역 안에 있음’으로 바꾸지 않으며 원본 데이터의 값을 변경하지 않는다. 조건 이름을 알 수 없는 경우 상세 확인을 안내하고 원본 JSON을 보존한다. 표시 문자열과 JSON은 textContent로 넣는다.

## 설치된 Ollama 모델 선택

인증된 `/api/ai/models`가 provider와 같은 로컬 Ollama 주소의 `GET /api/tags`를 조회한다. 이는 모델을 로드하는 요청이 아니다. 조회 제한 시간은 3초다. [Ollama 공식 모델 목록 API](https://docs.ollama.com/api/tags)를 사용한다.

설정 → 로컬 AI → 설치된 Ollama 모델에서 선택한 뒤 ‘AI 설정 저장’을 누른다. 현재 저장 모델을 유지하며 목록의 첫 모델을 자동 저장하지 않는다. 모델 목록 새로고침을 제공하고, 목록에 없는 기존 저장 모델도 선택 항목으로 유지한다. 직접 입력을 선택하거나 Ollama가 꺼짐·조회 실패·설치 모델 없음이면 수동 모델명 입력을 사용할 수 있다.

실제 PC에서 자동 조회한 모델은 다음 두 개다.

- `qwen3.5:4b`
- `qwen3:8b`

기존 저장 함수와 provider는 변경하지 않았다. 선택한 모델명을 문자열로 기존 settings 저장 경로에 넘기므로 기존 세션 초기화 및 실제 provider의 model 적용 방식도 유지한다.

## 선택 모델 저장·호출 확인

시험용 settings에 `qwen3.5:4b`를 저장하고 읽은 값으로 기존 provider를 생성했다. 실제 로컬 Ollama `/api/chat` 호출이 정상 JSON 응답을 반환했다. 기록된 저장 모델과 provider 모델은 모두 `qwen3.5:4b`이며, 현재 사용 중인 settings 파일은 변경되지 않았다. 실제 호출은 짧은 연결 확인용 요청이었다.

별도로 실제 localhost HTTP 서버를 사용한 시험에서 모델 목록 조회 → 인증된 설정 저장 → 동일한 AI 세션의 채팅을 실행했다. 시험용 Ollama 서버가 받은 요청의 model은 최초 `qwen3.5:4b`, 설정 변경 후 `qwen3:8b`였다. schema format·think·stream 옵션도 유지됐다.
