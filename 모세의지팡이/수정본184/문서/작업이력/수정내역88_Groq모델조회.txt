수정본88: Groq 실제 모델 조회

모델 목록은 Groq API가 실제 반환한 활성 모델 ID만 표시한다.
키 미입력·키 오류·조회 실패·빈 응답에서는 선택 목록을 비우고 오류를 표시한다.
모델명 직접 입력은 가능하며 이미 저장하거나 입력한 모델명은 유지한다.
빈 모델 입력을 자동으로 채우지 않는다.
Gemini와 Groq는 동일한 공통 UI 모델 선택 함수를 사용한다.
Groq 요청에는 MOSES/1.0 User-Agent를 명시해 관측된 접속 차단을 해결한다.
인증정보 비노출, TLS 검증, 리다이렉트 차단과 저장 전 키 확인은 유지한다.

운영 파일
common_ai/groq.py
Part3/lab/server.py
Part3/web/unified.js

검증
관련 Python 검사 144 PASS, FAIL/ERROR/SKIP 0.
Groq 브라우저 검사 15 PASS, 기존 모델 선택 브라우저 회귀 10 PASS.
키 없음·HTTP 오류·연결 예외·빈 목록에서는 목록이 비고 수동 모델명은 유지된다.
정상 조회 시 실제 모델 ID가 표시되고 선택한 ID가 정확히 저장된다.
키 저장·교체·삭제와 기존 Gemini 동작을 확인했다.
실제 사용자 키를 사용하지 않고 합성 응답으로 검사했다.
