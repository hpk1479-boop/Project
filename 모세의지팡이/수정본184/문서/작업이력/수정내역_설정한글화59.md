## 화면 변경

설정 화면의 저장용 영문 이름을 사용자용 한국어 이름으로 표시하고 각 항목에 짧은 설명을 붙였다. 현재 라이브 설정 37개, 백테스트 설정, 컴퓨터별 연결 위치, 전략 생성 AI 설정을 다룬다. 초·밀리초·거래일·포인트 단위를 명시하고 시간 입력과 쉼표 목록의 예시를 제공한다. 연결 키와 채팅방 번호는 기존처럼 화면에 노출하지 않는다.

| 기존 화면 표현 | 변경된 화면 표현 |
|---|---|
| TELEGRAM_TOKEN | 텔레그램 봇 연결 키 |
| TELEGRAM_CHAT_ID | 알림을 받을 채팅방 |
| STAFF_STALE_SEC | 데이터 지연 판정 시간(초) |
| WONBI_SIGMA | 원비 밴드 폭 배수 |

| overlap_trading_days | 앞 구간을 함께 읽을 기간(거래일) |
| work_size / MONTH | 데이터 작업 구간 크기 / 한 달씩 |
| FORTNIGHT / WEEK / DAY | 2주씩 / 1주씩 / 하루씩 |

| python_executable | 실행에 사용할 파이썬 프로그램 |

켜기·끄기 및 백테스트 작업 방식은 한국어 드롭다운으로 표시한다. 종목 연결은 기존 항목의 두 종목명을 입력하고 추가·삭제하는 형태로 바꿨다. 한쪽 이름이 비어 있거나 프로그램 종목명이 중복되면 한국어 안내를 보여 주고 저장하지 않는다. 기존 연결 목록을 변경하지 않고 저장하면 추가 쓰기 요청을 보내지 않는다.

라이브·백테스트의 공용 전략 설정 카드에서도 ‘최종 OZ 트리거’는 ‘최종 알림 조건’, ‘코드 기본값’은 ‘전략 기본 설정’으로 바꿨다. ASIA/LONDON/NEWYORK는 아시아/런던/뉴욕으로 표시하며 시작·종료 입력에 한국어 예시와 접근성 이름을 붙였다. 내부 SPECIAL 번호, 시간대 키, 선택값은 유지한다.

설정 오류에 영문 저장 항목명이 포함되면 화면에서는 해당 한국어 항목명으로 바꿔 안내한다. 각 영역에 저장 후 적용 시점을 안내했고, 라이브 명령용 Gemini와 전략 생성용 Ollama의 용도를 구분했다.

## 유지한 사항

한국어 표시와 편집 UI를 바꿨으며 저장용 항목명과 값의 형식은 그대로 유지했다. 예를 들어 ‘켜기’는 기존 `true` 문자열, ‘1주씩’은 `WEEK`, 자동 작업 수는 `null`, 종목 연결 행은 기존 `broker_symbols` 객체로 전송한다. 알 수 없는 기존 선택값도 자동으로 변환하거나 저장하지 않는다.

설정 API·검증·저장 구현, AI schema·Recipe v2·validator/compiler, Part1/Part2는 수정하지 않았다. 실제 사용자의 설정값을 저장하거나 매매·백테스트 엔진을 실행하지 않았다.

제품 파일은 `Part3/web/unified.js`, `Part3/web/index.html`, `Part3/web/style.css` 3개만 수정했다. 회귀 시험 `Part3/tests/test_settings_korean59.cjs` 1개를 추가했다.

## 검증

관련 시험 **55개 통과**:

- 새 설정 UI 13개: 37개 라이브 항목의 한국어 표시·설명, 접근성 안내, 비밀값 숨김, 변경 없는 저장, 켜기/끄기 및 작업 방식 선택, 숫자/null 저장 형식, 종목 연결 편집·삭제·입력 오류, 비밀값 변경/삭제, 한국어 오류, 알 수 없는 기존 값 보존, 공용 전략 설정 표시, 반응형 화면.
- 기존 한국어 해석·모델 선택 UI 12개, 전략 생성 화면 UI 8개.
- 수정형 AI 대화의 실제 웹/HTTP 흐름 7개.
