# 수정본57 — Ollama 모델 설정값 적용

2026-10-01. 수정본56을 복사해 수정본57에서 작업했다. 이전 `검증결과` 폴더와 Python/pytest 캐시는 복사하지 않았다. 이번 검증 결과는 수정본57에서 새로 생성했다.

## 사용법

`START_MOSES.pyw` 실행 → 오른쪽 위 설정 → **로컬 AI → Ollama 모델명**에 사용할 이름을 입력 → **AI 설정 저장**.

기본값은 `qwen3:8b`다. `qwen3.5:4b` 등 다른 Ollama 모델명도 입력·저장할 수 있다. 저장한 값은 `Part3/projects/ai_settings.json`의 `model`로 보관되며 다음 AI 요청에 적용된다. 설정 저장 후 AI 연결 표시도 새 모델명으로 갱신한다. 모델 설치 여부나 해석 품질은 이 변경에서 검증하지 않았다.

## 구현

- `lab/ai/provider.py`: `qwen3:8b`는 기본값 상수 `DEFAULT_MODEL` 한 곳에만 둔다. Provider는 settings의 모델명을 받고 실제 Ollama `/api/chat` JSON의 `model`에 넣는다. 모델 없음 오류도 선택한 이름으로 안내한다. 기존 생성자 timeout 인자 사용은 유지한다.
- `lab/server.py`: 저장된 `model`을 읽으며, 모델 설정이 없을 때만 기본값을 사용한다. `/api/ai/settings` 저장은 통합 설정의 저장 함수와 같은 검증·저장 경로를 사용한다.
- `lab/unified_settings.py`: 모델명·응답 제한 시간을 각각 또는 함께 저장한다. 모델만 바꾸면 timeout을, timeout만 바꾸면 모델을 유지한다. 성공 시 기존 AI 세션 캐시를 비워 다음 요청의 Provider가 새 설정으로 생성되게 한다.
- `web/unified.js`: 모델명을 읽기 전용에서 입력 가능한 필드로 변경했다. 모델명은 문자열로, timeout은 숫자로 전송한다.
- `web/ai_chat.js`: AI 설정 저장 후 연결 상태의 모델명을 다시 조회한다.

공백으로만 된 모델명, 문자열이 아닌 값, 모델명 내부 공백·제어 문자와 잘못된 timeout은 저장하지 않는다. 모델 목록을 특정 이름으로 제한하지 않는다. 기존 로컬 Ollama 연결 주소·구조화 출력 schema·tools·think·context 옵션은 유지한다.

## 변경 범위

제품 코드 **5개 수정**: `Part3/lab/ai/provider.py`, `Part3/lab/server.py`, `Part3/lab/unified_settings.py`, `Part3/web/unified.js`, `Part3/web/ai_chat.js`.

기존 테스트 **1개 수정**: `Part3/tests/test_ai_agent.py`의 설정 모델을 무시해야 한다는 검사를 설정값 사용 검사로 바꿨다. 새 회귀 테스트 **2개 추가**: `test_ai_model_settings57.py`, `test_ai_model_ui57.cjs`.

Part1 **286개**, Part2 **1,729개** 복사 파일은 수정본56과 내용이 같다. 기존 백테스트 UI 최적화도 유지한다. schema·Recipe 변환/검증·compiler·agent 로직은 수정하지 않았다. `ai/schema.py`, `ai/intent.py`, `compiler.py`, `ai_compiler.py`, `catalog.py`, `ai/agent.py`의 동일 파일 해시를 `검증결과/AI모델설정/unchanged_contracts.json`에 기록했다. 이는 변경 범위 확인이며 과거 알림을 정답으로 사용하는 검증이 아니다.

## 검증

- Python **67개 통과**: 새 모델 설정 시험 10개와 기존 AI Agent·Recipe/생성·intent·통합 웹 계약 시험. 설정이 없는 경우 기본값, 모델 저장/조회, 실제 Provider 요청 body, 같은 세션 ID의 저장 후 모델 변경, 모델/timeout 부분 저장, 잘못된 값의 기존 설정 보존, 404 안내, 다른 이름, 설정 파일 위치 변경을 확인했다.
- 모델 설정 UI **4개 통과**: 기본값·편집 가능 여부, `qwen3.5:4b` 문자열 저장, AI 연결 표시 갱신, timeout만 저장, 기본 모델로 재선택. 현재 HTML·JS를 격리된 Edge에서 실행하고 API를 대체했다.

총 **87개 관련 시험 통과**. HTTP 저장·조회·채팅 시험은 실제 localhost 서버에서 실행하고 Ollama 응답만 대체했다. 실제 Ollama 모델 다운로드·추론, MT5·백테스트는 실행하지 않았다. 모델이 기존 schema에 맞는 출력과 도구 호출을 지원하는지는 그 모델의 별도 실모델 시험이 필요하다.
