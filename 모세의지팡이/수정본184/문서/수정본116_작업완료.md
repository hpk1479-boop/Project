## 1. AI 편집 화면의 level_gate 오류 (수정함)

| 항목 | 내용 |
|---|---|
| 증상 | 외부유동성 거리 검사(`level_gate`)가 들어간 정상 전략에서 "이 항목은 슬롯으로 수정할 수 없습니다"가 표시됨 |
| 원인 | 편집기가 `level_gate`(객체) 칸을 만드는 방법을 몰라 "지원하지 않는 항목"으로 처리해 오류 목록에 넣음 |
| 수정 | `Part3/web/ai_editor.js`: `level_gate`가 있으면 `연결할 외부유동성 터치`(선택), `ATR 기간`, `ATR 배수` 칸을 표시. 연결 대상은 이 전략의 외부유동성 터치 캡처 중에서 고름. 기간·배수를 비우면 항목이 빠지고(기본 ATR 규칙) 칸에는 `기본값 사용`이 보임. 스키마에 없는 항목은 이전처럼 지원 안 함으로 표시 |
| 바뀌지 않는 것 | 스키마, 계약 검증, 엔진, `level_gate`가 없는 전략의 화면 |

시험(`tests/test_level_gate_editor116.py` + `.cjs`, Edge에서 실제 출하 SPECIAL2 해석 사용)
- 상세 보기에서 오류·붉은 표시 없음, 초안이 그대로
- 세 칸의 현재 값(`sweep`, 14, 1.5) 표시, 값을 고치면 초안의 `level_gate`만 바뀜
- 비우면 항목이 빠지고 오류가 아님, 범위 밖(0)이면 그 칸에 숫자 안내
- 없는 캡처를 가리키면 선택지에서 올바른 대상 선택 가능, `level_gate`가 없으면 칸이 생기지 않음
- 수정본115의 편집기로 같은 시험을 돌리면 첫 확인에서 실패(오류 재현)
- 편집기를 쓰는 기존 시험 43건 통과(`test_summary109`, `test_candle_ai107`, `test_virtual_ai113` 포함)

## 2. 백테스트 결과 "손익비 분석 없음" (확인만 함, 수정하지 않음)

확인한 것
- 최근 두 완료 실행(`cc29c3e9…`, `a81327ff…`)의 저장 결과는 정상입니다. `analytics.json`이 있고 RR 1.0~5.0 아홉 개가 모두 들어 있으며, 백엔드 읽기 함수도 `ready`를 돌려줍니다. 분석 계산은 12.6MB 거래 파일 기준 0.7초입니다.
- 대시보드는 `analytics.rr_results`가 비어 있으면 손익비 목록에 "분석 없음"을 넣고 요약 탭에 `virtual_entry.summary` 표(손익비별)만 보여 줍니다. 증상과 같습니다.

원인으로 보는 것(코드 경로로 확인, 사용자 화면에서 직접 재현하지는 않음)
1. 실행이 끝나면 러너가 `result.json`을 먼저 씁니다(`Part2/event_backtest/runner.py:399`, 분석 경로 없음).
2. 그 뒤에 별도 단계가 `analytics.json`을 쓰고 `result.json`을 다시 씁니다(`Part2/event_backtest/workflow.py:82-85`). 최근 실행에서 두 파일은 약 1.3초 간격입니다.
3. 화면은 `result.json`이 생기자마자(`result_ready`) 결과를 한 번 읽습니다(`Part3/web/unified.js:1138-1141`). 작업 상태가 완료인지는 기다리지 않습니다.
4. 그 시점에 분석이 아직 없으면 "분석 없음"이 그려지고, `resultShown`이 켜져 다시 읽지 않습니다(`unified.js:1055`, `1037`). 그래서 페이지를 새로 열거나 결과를 다시 불러오기 전에는 그대로입니다.

알림이 많은 실행일수록 분석이 늦어져 자주 걸립니다.

고치는 방향(요청 시 진행): 결과 화면은 작업이 완료 상태이거나 분석 파일이 준비된 뒤에 그리고, 분석이 아직 없으면 다음 확인 때 다시 읽기.
