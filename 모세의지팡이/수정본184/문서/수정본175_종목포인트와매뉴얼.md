## 1. 종목별 1포인트 가격 칸

| 파일 | 바뀐 것 |
|---|---|
| `Part3/lab/unified_settings.py` | `_symbol_points()`가 감시 종목(`SYMBOLS`)마다 `POINT_<종목>` 빈 칸을 만든다. 화면 목록(`read`)과 저장 허용 목록(`_save_live`)에 함께 쓴다. 처음 저장하면 파일 끝에 줄을 붙이고, 다른 줄은 그대로 둔다. |
| `Part3/web/unified.js` | `POINT_` 칸이 비어 있으면 흐린 예시 `예: 0.01`을 보여 준다. |
| `Part1/program/config.txt` | 개발본(새로 설치하는 PC용) 기본값 `POINT_NAS100=0.01`을 넣었다. |
| `통합설치/releasekit/agent_rules.md` | point가 없으면 사용자에게 설정 화면에 넣어 달라고 알리라는 문장으로 고쳤다. |

- 칸은 설정 → 라이브 감시 설정 → 상세 설정 → 지표에 "○○ 1포인트 가격"으로 보인다. 원래 있던 `POINT_` 칸과 같은 자리다.
- 값은 0보다 큰 수만 받는다. 0, 음수, 글자, 빈 값, nan은 거절한다.
- 감시 종목이 아닌 이름은 저장을 거절한다.
- 이름이 설정 파일의 `KEY=VALUE` 줄 형식(`POINT_[A-Z0-9_+]+`)에 맞지 않는 종목은 칸을 만들지 않는다. 예: `US30.cash`. 화면의 설정 줄 형식이 원래 그렇기 때문이고, 그런 종목은 예전처럼 칸이 없다.
- 이 값은 가상진입에서 스프레드(포인트)를 가격으로 바꿀 때만 쓴다(`virtual_entry.pricing`). 실시간 알림(Part1)은 이 값을 읽지 않는다.
- 업데이트해도 사용자 `config.txt`는 그대로 남는다. 그래서 이미 설치한 PC는 화면의 빈 칸에 한 번 넣으면 된다.
- NAS100 값 0.01의 근거: 녹화된 나스닥 가격이 소수 둘째 자리까지만 있다(알림 216개 중 셋째 자리 이상 0개). MT5 종목 사양으로 한 번 확인하면 된다.

## 2. 매뉴얼

PDF를 마지막으로 만든 것은 10/07(수정본147 무렵)이다. 172는 원본 글만 고치고 PDF는 만들지 못했다. 이번에 그 뒤 기능을 실제 화면 문구로 확인해 넣고, 두 PDF를 다시 만들었다.

| 장 | 넣거나 고친 것 |
|---|---|
| 차례 | "이번 버전에서 달라진 점"을 172~175 기능으로 바꿈 |
| 2장 설치 | 업데이트 표에 `스페셜/기본`·내 전략 구분 추가, "전략 파일을 주고받을 때"(스페셜/내 전략, 166) |
| 7장 백테스트 | 스프레드에는 1포인트 가격이 필요하다는 한 줄. 새 쪽 "여러 조건을 한 번에 비교해요": 함께 비교(161), 트리거 함께 비교(171), 알림 재사용(154), 당시 설정(169). 새 쪽 "결과 화면 읽기": RR 비교·등급 색·흐린 줄, 시간대 선정, 복리 계좌, 탭(165) |
| 8장 AI 전략연구 | 새 쪽 "사건 뒤 기간과 최근 사건 취소"(173). 새 쪽 "클로드 코드·코덱스로 대량 백테스트"(174) |
| 9장 설정 | 상세 설정 그림·표: 브로커 서버 시간(172), 종목 1포인트 가격(175). 백테스트 설정 그림·표: 최적화(167). 네 묶음 표 |
| 10장 도움말 | "종목 point 값이 없습니다" 한 줄 |

- 그림 두 장(`set_live_details.png`, `set_part2.png`)은 실제 화면 파일을 Edge에 올리고 설명용 값을 넣어 다시 찍었다. 도구는 `검증결과/revision175/tools/capture_settings175.cjs`다.
- 다른 설정 그림은 10/07 촬영 뒤 해당 화면 코드가 바뀌지 않아 그대로 두었다(138→140 변경 없음, 140→175 변경은 위 세 기능뿐).
- 동시 작업 수 설명에서 기간을 나누는 방식 문장은 뺐다. 168 이후 실제 나누는 방식과 맞지 않을 수 있는 내부 설명이었다.
- 간단사용서: 날짜, 파트2 스프레드·결과 보기(RR 비교, 당시 설정), 파트3 클로드 코드·코덱스 한 줄.
- `제작.py`·`간단사용서_제작.py`의 필수 문구 검사를 고쳤다. 표 칸에서 줄이 바뀐 문구도 찾고, 없어야 할 옛 문구도 같은 방식으로 찾는다(검사가 더 엄격해짐).
- 결과: 사용자 매뉴얼 49쪽, 간단사용서 3쪽. 쪽 넘침·필수 문구·깨진 글자·절대 경로 검사를 통과했다. 바뀐 쪽 10장과 간단사용서 3쪽은 화면으로도 봤다(`검증결과/revision175/manual/review/`).
