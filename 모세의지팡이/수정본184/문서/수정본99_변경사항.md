# 수정본99 변경사항

수정본97을 기준으로 작업했습니다. 수정본98의 이벤트 모드 실험은 포함하지 않습니다.

- Part3에서 생성한 Recipe v2 전략은 Part1 라이브 감시와 Part2 백테스트의 공통 전략 목록에 자동 등록됩니다. 새 전략의 라이브 실행은 기본으로 꺼져 있으며 전략설정에서 선택한 뒤 감시를 시작합니다.
- 두 파트의 전략설정에 선택삭제와 리셋을 추가했습니다. 실행 체크와 삭제 선택 체크는 별도입니다. 기본 스페셜은 목록에서 숨기며 리셋으로 복구합니다. 추가 전략은 Python 파일과 Recipe 설정을 삭제하며 리셋으로 복구하지 않습니다. 실행 중인 감시 또는 백테스트가 있으면 먼저 종료해야 합니다.
- 기본 스페셜의 기준은 현재 배포본의 `settings/strategy_registry.json`입니다. 새 버전에서 7개를 4개로 줄이면 업데이트 후 4개만 표시하고 리셋도 4개만 복구합니다.
- Setup은 기존 설치 위치를 찾아 같은 폴더를 업데이트합니다. 신규 설치는 사용자 문서의 MOSES 폴더가 기본입니다. 기존 위치는 사용자별 설치 기록, 기본 폴더, MOSES 바탕화면 바로가기를 통해 탐색합니다.
- 사용자 설정, 추가 전략, 데이터와 결과는 유지하고 새 프로그램·기본 스페셜·라이선스를 교체합니다. 이전에 삭제한 추가 전략은 재생성하지 않습니다. 설치 중 실패하면 교체한 프로그램과 MT5 파일을 이전 상태로 되돌립니다.
- 첫 설치는 MT5 데이터 폴더를 탐색하며 여러 개라면 대상을 선택합니다. EA는 `MQL5/Experts`, PRICE·RSI·STO·DI는 `MQL5/Indicators`로 복사합니다. 선택한 위치는 다음 업데이트에도 사용합니다. MT5 위치를 찾지 못하면 다시 선택할 수 있습니다.
- EX5는 MOSES의 `Part1/program/MT5`에도 보관합니다. 자동 복사 없이 직접 복사하는 방법을 선택할 수 있습니다. 설치 화면의 MT5 파일 폴더 열기 버튼은 제거했습니다.
- 새 아이콘은 금색 M과 나무 지팡이의 원형 디자인입니다. 바탕화면 바로가기, 프로그램 EXE, Setup EXE와 프로그램 창에 적용했습니다.
- 개발자용 실행 환경이 없는 경우 프로젝트의 `.moses-runtime` 공용 환경을 처음 한 번 준비합니다. 이후 수정본에서 같은 Python 버전과 요구 패키지를 재사용합니다. 공용 실행 환경은 배포 준비 캐시와 별개이며 수정본 폴더에 중복 포함하지 않습니다.

배포는 `배포만들기.cmd`에서 버전·프로그램 만료일·설치파일 유효시간을 지정합니다. 준비 캐시 세 폴더는 Setup 생성 후 기존 방식대로 삭제합니다. 검증용 Setup은 사용자 배포 파일과 혼동하지 않도록 정리했습니다.

검증: 배포 도구 287개 테스트, 개발자 UI와 공통 전략 61개 테스트, 숨김 Edge UI 4개 검사, 실제 frozen EXE의 라이브러리·HTTP·전략 생성/삭제/리셋·WebView 화면 검사. 신규 설치/업데이트와 MT5 교체/실패 복구는 격리한 Windows 임시 폴더에서 검증했습니다. 실제 새 PC에서 WebView2 설치와 사용자 MT5를 연결하는 최종 확인은 별도입니다.
