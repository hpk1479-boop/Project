# 수정본137 가상진입 개편

136에서 복사해 만들었다. 요구사항은 `문서/요구사항_가상진입개편.md`(1~12번)에 사용자 말 그대로 적혀 있다. 라이브 알림(파트1)과 알림 판정은 바꾸지 않았고, 바꾼 것은 알림 뒤의 가상진입뿐이다.

## 바뀐 동작

- **진입 방식**: 즉시 진입 / 조건 진입 두 가지만 있다. "자동"은 없앴다.
- **전략 기본값**: 전략을 고르면 그 전략의 기본값이 실제 값으로 채워진다. 고르는 항목이 아니다.
  - 올존 트리거가 있는 전략(최종 행동이 올존): 조건 진입, 조건은 양봉·음봉 마감 + HMA6 위·아래, 손절 올존 B0
  - 그 밖의 전략: 즉시 진입, 손절 ATR
  - 다른 전략도 조건 진입으로 바꾸면 양봉·음봉 마감 + HMA6 위·아래가 채워진다.
- **양봉·음봉 마감**: 예전 확인 진입에 고정으로 붙어 있던 검사다. 이제 조건 목록의 한 항목(`CANDLE_CLOSE`)이라 지울 수 있다. 조건 진입에는 조건이 1개 이상 있어야 한다.
- **시간봉**: "신호 프레임 · 자동" 대신 전략의 실제 알림 시간봉을 보여 준다(예: SPECIAL5 "1분·2분·3분", SPECIAL7 "1분"). 판정 방식은 그대로다. 조건은 하나이고, 알림마다 자기 시간봉으로 본다(5분 알림은 5분봉 HMA6). 목록에서 5분 같은 하나를 고르면 모든 알림을 그 봉으로 본다.
- **확인봉 따라가기**: 확인봉 시간봉을 바꾸면, 확인봉과 같은 시간봉이던 조건과 손절도 같이 바뀐다.
- **손절**: 올존 전략은 올존 B0 / 직전 N봉 저점·고점 / ATR이고, 그 밖의 전략은 B0 없이 두 가지다.
  - 고른 방식의 칸만 보인다. B0는 칸이 없고, N봉은 시간봉·봉 수, ATR은 시간봉·기간·배수다.
  - 손절 ATR 기간은 손절 칸에 따로 있다(`stop.period`). 따로 있던 "ATR 기준" 칸은 없앴고, 진입 제한을 추가했을 때만 그 아래에 ATR 시간봉·기간이 보인다.
- **전략 개수**: 가상 진입은 전략 1개만 돌린다. 알림 온리는 라이브처럼 여러 개를 함께 돌린다.
  - 가상 진입일 때 전략 설정 창에서 하나를 체크하면 나머지가 풀리고, 전체선택은 막힌다.
  - 여러 개가 골라져 있으면 "가상 진입은 전략 1개만 선택할 수 있습니다."가 보이고, 엔진도 실행을 거부한다.
- **WATCH**: 명령 문장에서 올존 여부와 시간봉(예: "5분")을 읽어 기본값을 채운다.
- **저장**: 마지막 실행의 정책은 그 전략 이름과 함께 저장되고, 같은 전략을 다시 고를 때만 돌아온다. 예전 형식(schema 1, 자동 포함)의 저장값은 변환하지 않고 버린다. 그러면 전략 기본값이 다시 채워진다.
- **화면 문구**: 설명 문장을 뺐다. 익절은 "손익비 1:1 ~ 1:5 (0.5 간격) 비교" 한 줄이다.
- **AI**: 백테스트 요청 지시문과 전략연구 지시문에서 AUTO를 없앴다.
  - 진입·손절을 말하지 않으면 `virtual_entry`는 null이고, 실행 때 전략 기본값이 채워진다.
  - 미리보기에는 실제 시간봉으로 표시한다.
  - 가상 진입에 전략을 여러 개 요청하면 하나를 고르라고 묻는다.

## 이전과 결과가 달라지는 경우

| 경우 | 이전 | 지금 | 판단 |
|---|---|---|---|
| 올존 전략을 기본값으로 실행 | 자동 = 확인 진입 + HMA6 + B0 | 조건 진입(양봉·음봉 마감 + HMA6) + B0 | 같음 |
| 그 밖의 전략을 기본값으로 실행 | 자동 = 즉시 진입 + ATR | 즉시 진입 + ATR | 같음 |
| 확인 진입 + 조건을 직접 지정 | 양봉·음봉 확인이 항상 붙음 | 양봉·음봉 마감 조건이 목록에 있을 때만 확인 | 화면에서 조건 진입을 고르면 양봉·음봉 마감이 채워지므로 그대로 두면 같음. 사용자가 빼면 확인하지 않음(요구사항 10·11) |
| 최종 행동은 일반 알림인데 OZ_ALERT 단계로 끝나는 전략 | 그 올존 알림만 확인 진입 + B0 | 전략 기준이라 즉시 진입 + ATR | 요구사항 12("전략에 올존 트리거가 있으면")에 따른 것. 기본 스페셜 8개에는 이런 전략이 없음 |
| 가상 진입에 전략 여러 개 | 함께 실행 | 실행 거부 | 요구사항 3·4 |

## 함께 고친 것

- 136에서 배포 도구에 간단사용서를 넣으면서 매뉴얼 검사 함수가 목록을 받게 바뀌었는데, `tests/test_telegram_release108.py`가 예전 방식으로 부르고 있었다. 136은 배포 도구 시험만 돌려 이를 놓쳤다. 137에서 시험을 고쳤다. 제품 동작에는 영향이 없다.
