# 수정본112 스페셜 알림 정리

스페셜 전략과 Part3에서 생성한 새 전략의 공통 알림에서 `조건`, `트리거`, `등급` 줄을 제거했습니다. 표시를 숨기는 옵션이나 별도 예외 경로는 추가하지 않았습니다. 조건 설명을 합치던 `_steps_text` 함수도 삭제했습니다.

`Part1/program/strategy_recipe/alerts.py`에서 문구만 변경했습니다. 전략명, 매수·매도, 종목, 위치, 주기, 지표, 현재 가격 표시는 유지합니다. 조건 표현 함수는 현재 위치 표시에도 쓰이므로 유지합니다. 내부 신호의 등급·트리거 정보, 전략 조건과 판정, 알림 시각과 수신자, 중복 방지는 변경하지 않았습니다. 개인 WATCH 알림도 변경하지 않았습니다.

아래는 합성 이벤트로 확인한 표시 예시입니다.

```text
[새로운 전략] 🟢 매수 신호 발생
──────────────────
• 종목: TEST
• 위치: 5분 EMA50 가격 터치
• 주기: 5분 무지성 브레이커 올존
• 지표: PRICE·RSI·STO
• 현재 가격: 2,400.25
──────────────────
```

검증은 `tests/test_recipe_alerts101.py`와 `tests/test_recipe_alerts112.py`의 32개 테스트가 통과했습니다. 실제 스페셜 7개 등록 및 Part3 컴파일러가 만든 새 전략의 등록 경로에서 매수·매도 이벤트를 전달하여 출력 경계를 확인했습니다. 최종 조건이 불충족하면 알림이 발생하지 않는 경우와 기존 개인 WATCH 문구 유지도 확인했습니다. 실제 텔레그램 전송은 차단했습니다.

`Part3/tests/test_common_recipe60.py`의 실제 LIVE Wire 수신 및 Part2 캡처 재생 비교도 통과했습니다(1개 테스트, 3개 하위 사례). 같은 합성 입력에서 최종 알림과 전략 상태가 일치합니다. 장기간 실데이터 백테스트를 수행한 결과는 아닙니다.

소스 코드 없는 배포 구성의 동일 문구와 생성 경로는 `tests/test_notifications_release112.py`에서 별도로 확인했습니다.
