# 수정본162: 틀린 시험 고치기와 시험 정리

수정본161을 별도 폴더로 복사해 작업했다. 이전 검증결과는 복사하지 않았다.
**제품 코드(Part1·Part2·Part3·common_ai)는 바꾸지 않았다.** 바뀐 것은 시험, 공식 검사 목록(`verify_current_manifest.json`), `CURRENT_VERIFY.md`뿐이다.

## 요청과 기준

- 사용자 지시(2026-10-08): "잘못된 테스트라면 이번 작업 끝나고 고쳐"(161 뒤). 작업 중 "테스트 억지로 다 살리지 말고 지울건 지우고 고칠건 고쳐".
- 사용자가 준 정리 기준:

| 시험 | 처리 |
|---|---|
| 삭제된 기능(LoRA 등)·옛 화면 구조를 확인하는 시험 | 삭제 |
| 같은 동작, 같은 캐시·계산을 여러 수정본에서 검사 | 하나로 합침 |
| 문구·칸 개수·내부 호출 횟수만 고정 | 필요성 보고 후 정리 |
| 과거 버전 비교·속도 측정 | 상시 검사에서 분리 |
| 전략 조건, 확정봉·진행봉 경계, LIVE↔재생, 캐시 계산 정확성, 서로 다른 오류를 잡는 조건·경계 | 유지 |

- 시험이 틀렸으면 고치거나 지우고, 코드가 틀렸으면 고치지 않고 보고한다.

## 4. 분리한 시험 — 과거 버전 비교·속도 측정

- 새 폴더 `비교측정시험/`(README 포함). 기본 시험 실행과 `verify_current.py`는 이 폴더를 돌리지 않는다.
  - `test_ea_live_block_past.py`: EA 실행부(`int OnInit()`부터)가 수정본23·34와 같은지. `tests/test_part2_event_runner.py`·`tests/test_symbol_registry.py`에서 옮겼다.
  - `test_summary_baseline108.py`: AI 핵심요약 카드가 수정본108보다 작은지. `tests/test_summary109.py`의 기준선 비교를 옮겼다.
  - 옛 수정본 위치는 환경변수 `MOSES_COMPARE_ROOT`로 받는다. 지정하지 않으면 건너뛴다. 프로젝트는 기본 실행에서 자기 루트 밖을 읽지 않는다(경로 규칙). 확인: 미지정 1 통과·3 건너뜀, 지정 4 통과.
- `verification/test_recipe_pipeline84.py`: 1만 번 실행 시간을 `검증결과/simple_rule_cost84.json`에 쓰던 측정을 뺐다. "단순 전략은 수명 조회를 안 한다" 확인은 유지했다.
- `verification/test_backtest_cancel111.py`: 실행할 때마다 `검증결과/revision111/...`에 쓰던 기록을 뺐다. 강제 종료 동작 확인은 유지했다.
- `tests/test_delta_materialization151.py`의 측정 코드는 원래 `--benchmark`로만 돈다. 그대로 두었다.
- 이번 작업 중 위 두 시험이 162 검증결과에 쓴 파일은 치웠다.
