# 수정본112 설정 하단 버전 표시

설정 화면의 맨 아래에 `버전 112`를 표시합니다. 기존 설정 영역이나 버튼 배치는 바꾸지 않았습니다.

## 버전 기준과 배포

- 개발본은 현재 프로젝트 폴더의 `수정본112`에서 수정본 번호를 읽습니다. 같은 코드를 `수정본113`으로 복사한 다음 실행하면 `버전 113`이 됩니다.
- 배포 만들기의 `prepare_data()`는 그때의 수정본 번호를 배포 데이터 `runtime/app_version.json`에 기록합니다. 형식은 `{"schema":1,"revision":112}`입니다.
- 배포본은 이 메타데이터를 우선 읽습니다. 설치 폴더를 다른 위치로 옮기거나 폴더 이름을 변경해도 실제 배포를 만든 수정본 번호가 유지됩니다.
- 다음 수정본에서 다시 배포를 만들면 같은 메타데이터 파일을 새 수정본 번호로 갱신합니다.
- 설치파일의 수동 배포명 `v1.0`과 설정 화면의 수정본 번호는 별개입니다. 라이선스 기간이나 개발자 경로를 메타데이터에 넣지 않습니다.

설정 API `GET /api/mo/settings`에 읽기 전용 `app_revision` 숫자를 추가했습니다. 화면은 이 값을 사용해 맨 마지막 `#settings-version`에 표시합니다. 버전 값을 알 수 없는 비표준 폴더나 손상된 메타데이터 때문에 설정 화면 전체가 실패하지 않도록 했습니다.
