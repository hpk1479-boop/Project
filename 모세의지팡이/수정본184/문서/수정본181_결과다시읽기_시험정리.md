## 1. 백테스트 결과 다시 읽기 (제품 수정 1곳)

**문제:** 정상 완료된 백테스트의 결과 읽기가 한 번 실패하면 다시 읽지 않았다. 결과 화면이 안 열리고, 결과 보기 버튼이 꺼진 채, 경고 칸에 오류 문구만 남았다. 화면이 결과를 읽기 전에 진행 확인을 끝내 버렸기 때문이다.

**고친 곳:** `Part3/web/unified.js`(백테스트 화면 코드) 한 파일.

- 정상 완료 + 결과 준비됨이면, 결과를 실제로 읽을 때까지 진행 확인을 계속한다(1.5초 간격).
- 3번 읽어도 실패하면 확인을 멈추고 오류를 보여 준다. 고치기 전과 같은 마지막 상태다. 그 뒤 실행 목록에서 작업을 다시 고르면 처음부터 다시 읽는다.
- 다시 읽는 동안 시작·중지 버튼은 꺼 둔다.
- 그대로: 오류·중단·끊김으로 끝난 작업(복구 카드와 다시 시도 버튼), 서버, 라이브·백테스트 계산.
- "3번"은 내가 정한 값이다. 결과 파일이 깨진 경우 끝없이 다시 읽으면서 시작 버튼이 계속 잠기지 않게 했다. 바꾸려면 숫자 하나만 고치면 된다.

**시험:** `Part3/tests/test_backtest_polling56.py`를 새로 붙여 이 화면 시험 17개 상황이 매번 돈다.

- 기존 16개 상황은 그대로다: 시작 중복 클릭 잠금, 300/1500ms 주기, 요청 겹침 없음, 늦은 옛 응답이 새 작업을 덮지 않음 등.
- 기존 "결과 읽기 실패 뒤 다시 읽기" 상황에 확인 2개를 더했다: 다시 읽는 동안 중지 버튼 꺼짐, 성공 뒤 시작 켜짐·중지 꺼짐.
- 새 상황 1개: 결과 읽기가 계속 실패하면 3번 뒤 멈추고(시작 켜짐·중지 꺼짐·오류 표시), 다시 열면 다시 읽어 결과를 보여 준다.

**확인:** 181의 이 시험을 고치기 전 화면 코드(180)에 대고 돌리면 결과 다시 읽기 2개 상황이 실패한다. 고친 코드로는 17개 모두 통과한다. 오류로 끝난 작업의 결과 읽기 실패는 `verification/test_backtest_recovery70.py`가 예전대로 확인한다(통과).
