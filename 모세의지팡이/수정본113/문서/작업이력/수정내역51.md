## 2. 핵심 수정 내용

### 구명칭의 실행·호환 지원 제거

`Part1/program/oz_profile_loader.py`에서 `DIVERGENCE → BREAKER` 변환, 한글 구명칭 치환, 구명칭을 조합한 별칭 목록, 구명칭 기반 체크포인트 식별자 추정을 제거했습니다.
프로필 로더는 현재 어휘 검증을 사용하며, 유효하지 않은 저장 프로필은 일반적인 `LegacyUnsupportedProfile` 보고 경로로 제외합니다. 구명칭만 특별 취급하는 차단 목록은 추가하지 않았습니다.

`Part1/program/oz_engine/runtime.py`는 현재 `BREAKER` 체크포인트 이름만 사용합니다. 구명칭 파일을 찾아 대신 복원하던 경로와 그 전용 이전 상태의 저장·복사 처리를 제거했습니다.
현재 `BREAKER` 상태의 저장·복원, 깊은 복사, 체인 진행·취소 및 재등록 동작은 유지됩니다.

구명칭 프로필로 저장된 Watch, TimedChain, 취소 트리거, SPECIAL 설정, Part2 설정, Part3 Recipe·수동 소스·초안은 자동으로 다른 프로필이 되지 않습니다.
미지원 설정은 해당 경계의 오류·격리 경로로 원본과 사유를 보고하며, 정상 프로필을 기본값으로 채워 재저장하지 않습니다.

현재 프로필은 `NORMAL/BLIND × OZ/BREAKER`의 네 조합입니다. `BLIND_BREAKER` 등 이미 존재하던 현재 어휘의 구형 필드 형식 처리는 유지하며, `DIVERGENCE` 계열의 값은 그 경로에서도 거부됩니다.

### TRUE B0 판정 유지

`monitor_OZ.py`의 `_breaker_bo_break_trigger()`는 설명 문구만 수정했습니다. 지표 검출기를 추후 연결한다는 문구를 없애고, 구조적 TRUE B0의 엄격 돌파 조건임을 명시했습니다.
**이 파일은 설명 문자열을 제외한 전체 실행 AST가 수정본50과 동일합니다.**

기존 판정은 다음과 같이 그대로입니다.

- LONG: 이전 봉 저가가 TRUE B0 이상이고, 현재 봉 저가가 TRUE B0 미만일 때만 새 돌파입니다.
- SHORT: 이전 봉 고가가 TRUE B0 이하이고, 현재 봉 고가가 TRUE B0 초과일 때만 새 돌파입니다.
- 단순 접촉·근접, 이미 돌파된 상태의 지속, HMA 교차 시점과 같거나 이른 봉, 결측 입력은 기존대로 돌파가 아닙니다.

배열 기반 `oz_engine/market.py`와 최종 판정 `oz_engine/profile.py`는 원본 그대로입니다. 실제 지표 다이버전스 계산은 추가하지 않았습니다.

### Part1·Part2·Part3·SPECIAL1~7 일치

Part1·Part2·Part3의 현재 공용 프로필·파서·UI는 이미 `BREAKER`를 사용하므로 불필요한 재수정을 하지 않았습니다. 남아 있던 Part3 참조 소스, 생성 Python, 내장 소스, recipe, 초안, 개발 템플릿 및 관련 진단 입력의 OZ 명칭을 통일했습니다.
수정한 Part3 참조·생성 Python **23개는 OZ 이름과 설명 문자열을 정규화한 AST가 기존과 동일**합니다. 전략 조건이나 SWEEP 조건을 다시 작성하지 않았습니다. 변경된 JSON 10개와 생성 소스의 대응 해시도 검증했습니다.

| 현재 SPECIAL | 최종 트리거 | 점검 결과 |
|---|---|---|
| SPECIAL1 | BREAKER | 실행 상수·카탈로그·새 생성 소스·표시명 일치 |
| SPECIAL2 | BREAKER | 동일 TF SWEEP 연계 정의 유지 |
| SPECIAL3 | OZ | 기존 정의 유지 |
| SPECIAL4 | OZ | 기존 정의 유지 |

| SPECIAL7 | NORMAL + BREAKER | 기존 15분 TREND → 1분 조건 유지 |

현재 `Part1/program/SPECIAL/SPECIAL1.py`부터 `SPECIAL7.py`까지 **7개 실행 파일은 수정본50과 바이트 단위로 동일**합니다.
SPECIAL5를 복구하기 위한 레짐 대체 OZ, 레짐 후보 추적기, 별도 B0 상태, 추가 필터는 만들지 않았습니다. 기존 Part3 예제에 남아 있던 자식 출처 별칭 이전 함수는 삭제했습니다.
미지원 레짐 조합을 가진 과거 `Test_SPECIAL012`·`Test_SPECIAL014`는 이름만 개명하며, 정상 프로필로 전략을 바꿔 살리지 않았습니다. 재열기 시 미지원 설정으로 제외되는 것을 시험했습니다.

다른 기능의 레짐 지표, SWEEP, FVG/WONBI, 범용 MA 계산기, WatchMAStore, 현재 자연어 파서·명령 별칭, 수정본49 MA/TimedChain 로직은 변경하지 않았습니다. 동봉된 외부 라이브러리도 수정하지 않았습니다.
OZ 구명칭의 명시적인 문자열은 거부 검증 입력과 과거 기록에 남으며, 실행 프로필이나 호환 별칭으로는 지원되지 않습니다.
