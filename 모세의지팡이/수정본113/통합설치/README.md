# 수정본111 모세의지팡이 배포

통합설치에는 **업데이트 / 설치** 버튼이 있습니다. 업데이트는 기존 MOSES를 자동으로 찾으며, 없거나 여러 설치본이 발견되면 업데이트할 폴더를 지정하라는 안내를 표시합니다. 버전별 선택 목록은 만들지 않습니다. 지정한 폴더에 기존 MOSES가 없으면 업데이트하지 않습니다. 설치는 별도 빈 폴더에 새로 설치하며 기존 MOSES 폴더를 덮어쓰지 않습니다. 사용자 설정·추가 전략·데이터·결과는 보존하며 라이선스와 기본 스페셜 구성은 새 배포본 기준으로 교체합니다. 바탕화면 바로가기는 자동 생성하지 않습니다.

MT5 목록에는 터미널 이름과 설치 위치를 표시합니다. 터미널 설치 폴더를 지정하면 `origin.txt`에 연결된 데이터 폴더를 찾습니다. 데이터 폴더 또는 그 안의 `MQL5/Experts/Indicators` 경로도 지정할 수 있습니다. 연결된 데이터 폴더가 여러 개라면 MT5에서 파일 → 데이터 폴더 열기로 확인한 폴더를 지정하라는 안내를 표시합니다. EA는 실제 데이터 폴더의 `MQL5/Experts`, 네 지표는 `MQL5/Indicators`에 복사합니다. 선택한 위치를 저장해 다음 업데이트에도 자동 교체합니다. 수동 복사용 EX5 5개는 설치 폴더 바로 아래의 `MT5` 폴더에 보관합니다. 내부 실행용 `Part1/program/MT5`와 동일한, 이번 배포에서 유효기간을 적용해 새로 컴파일한 파일입니다. MT5 위치가 바뀌면 다시 선택할 수 있습니다. MOSES와 MT5를 종료한 뒤 설치·업데이트하세요.

Part3에서 새 전략을 만들면 `Part3/TEST_SPECIAL` 폴더와 테스트 전략 목록에만 보관합니다. 목록에서 이름 변경·삭제·메인전략 승급을 할 수 있습니다. 승급하면 Part1·Part2 목록에 함께 등록되며 라이브 사용은 꺼진 상태로 시작합니다. 각 파트의 목록에서 제외해도 다른 파트의 등록과 Part3 원본은 유지됩니다. 다시 승급하면 빠진 등록만 복구합니다. Part3에서 실제 삭제하면 경고 확인 후 양쪽 등록·설정·파일이 삭제됩니다. 각 파트의 리셋은 기본 스페셜을 복구하고 해당 파트의 테스트 전략 등록을 해제하며 파일은 보존합니다.

새 배포본에는 개발자가 `Part1/program/SPECIAL`에 보관한 정식 스페셜만 포함합니다. Part3에서 생성·승급한 전략과 개발자의 목록 제외·승급 기록은 배포하지 않습니다. 테스트 전략을 정식 배포하려면 해당 `.py`를 정식 스페셜 폴더로 복사하고 중복되지 않는 `SPECIAL번호.py`로 이름을 변경하세요. `Part1/program/SPECIAL/관리안내.md`를 참고하세요. 정식 폴더의 전략 수를 줄이면 다음 배포본에도 그대로 반영됩니다. 기존 설치를 업데이트할 때는 받는 사람의 테스트 전략을 새 `TEST_SPECIAL` 폴더로 이관해 보존합니다.

개발자는 프로젝트 루트의 **모세의지팡이 배포.cmd**를 실행합니다. 작은 창에서 배포 버전(v1.0), 프로그램 만료일, 설치파일 유효시간(분)을 정하고 **모세의지팡이 통합설치 만들기**를 누릅니다. 만료일은 **1개월·3개월·6개월·12개월** 버튼 또는 직접 입력으로 지정합니다. 월말은 해당 달의 마지막 날로 맞춥니다. 생성된 파일은 `배포/<버전>_<빌드번호>/모세의지팡이 통합설치.exe`입니다. 선택한 버전은 폴더·EXE 버전 정보·라이선스에 기록됩니다. 설정창 자체는 빌드 패키지 없이 바로 열립니다.

매뉴얼은 개발자 수정본의 **매뉴얼/모세_사용자_매뉴얼.pdf**에 보관합니다. 내용을 수정한 PDF를 같은 이름으로 저장하면 다음 배포에 최신 파일이 포함됩니다. 배포는 실행한 수정본 폴더를 기준으로 읽으며, 설치 후 `MOSES/매뉴얼/모세_사용자_매뉴얼.pdf`에 들어갑니다. 업데이트 때도 최신 PDF로 교체합니다. 편집 원본과 안내서는 개발자 폴더에만 보관하며 배포하지 않습니다. PDF 누락·형식 표시 손상·빌드 도중 변경은 배포를 중단합니다. 원본·배포 복사본·통합설치 ZIP의 PDF를 해시로 비교하고 결과를 빌드 기록에 남깁니다.

버튼을 누르면 필요한 배포 도구와 WebView2 오프라인 설치파일을 자동 다운로드합니다. 기존 로그에 다운로드·생성·검증·정리 진행 상황을 표시합니다. 배포 작업 프로세스가 끝난 뒤 `통합설치/.work`, `통합설치/prerequisites`, `통합설치/.buildenv` 세 폴더를 자동 삭제합니다. 실패한 작업도 임시 파일을 정리하며, 오류와 검증 기록은 남깁니다. 파일 잠금 등으로 정리하지 못하면 로그에 해당 폴더를 표시합니다.

완성된 Setup EXE, 원본 프로그램, `.keys`, 검증 기록은 삭제하지 않습니다. 다음 배포에서는 준비용 파일을 다시 다운로드하므로 인터넷과 준비 시간이 필요합니다. 실행 중인 다른 배포 작업이 있으면 새 작업이 해당 파일을 다운로드하거나 삭제하지 않도록 차단합니다.

설치파일 유효시간은 컴파일과 최종 파일 복사가 끝난 발급 시점부터 시작합니다. 10분을 설정하면 그 안에 설치를 시작해야 합니다. 만료된 설치파일은 창과 오류 메시지 없이 종료합니다. 창을 미리 열어 두었어도 설치 버튼을 누르는 시점에 다시 검사합니다. 설치 중에 시간이 지나면 이미 시작한 설치는 끝까지 진행합니다.

프로그램 만료일은 실행 PC의 달력 기준입니다. 12월 31일이면 1월 1일 00:00부터 새 실행을 차단합니다. 실행 중인 프로그램을 중간에 종료하지 않습니다. 정상 화면에는 라이선스나 만료일을 표시하지 않습니다.

## 받는 사람의 설치와 실행

1. 받은 통합설치 EXE를 유효시간 안에 실행하고 설치합니다.
2. 기본 폴더는 받은 설치 EXE가 있는 위치의 `모세` 폴더이며 다른 빈 폴더를 선택할 수 있습니다. 숨김 폴더가 아닙니다. 다른 버전을 함께 보관하려면 별도 폴더를 지정하고 **설치**를 누르세요.
3. 설치 후 설치 폴더의 `MOSES.exe`로 실행합니다. Python과 라이브러리가 함께 설치됩니다. 바로가기가 필요하면 직접 만들어 사용하세요.
4. MT5는 직접 설치합니다. 통합설치에서 MT5 데이터 폴더를 선택하면 EA·지표를 자동 배치합니다. 수동 설치가 필요하면 설치 폴더의 `MT5`에 있는 EX5 5개를 사용하세요. EA는 MT5 데이터 폴더의 `MQL5/Experts`, 나머지 4개 지표는 `MQL5/Indicators`에 넣습니다.
5. 사용법은 설치 폴더의 `매뉴얼/모세_사용자_매뉴얼.pdf`를 열어 확인합니다.
6. 설치 또는 업데이트가 성공하면 통합설치 창이 자동으로 닫히고 실행했던 설치 EXE만 삭제됩니다. 취소·실패·유효시간 만료 때는 삭제하지 않습니다. 일시적인 파일 잠금은 최대 60초 동안 재시도합니다. Windows 권한이나 계속되는 파일 잠금으로 삭제하지 못하면 해당 EXE가 남을 수 있습니다.

Python 프로그램은 설치 PC에 등록됩니다. 설치 폴더를 다른 PC로 복사하면 Windows가 그 PC의 등록 정보를 해독할 수 없어 실행을 차단합니다. 같은 PC 안에서 폴더를 이동하면 `MOSES.exe`를 직접 실행할 수 있습니다. 이동한 위치에서 실행하면 새 위치를 기록해 다음 업데이트 때 찾습니다. 이동 후 실행하지 않았다면 업데이트 창에서 폴더를 직접 지정할 수 있습니다. 직접 만든 바탕화면 바로가기는 이동 후 다시 만들어야 합니다.

EA와 PRICE·RSI·STO·DI 지표는 만료일만 적용합니다. PC 제한은 없습니다. MT5 자체가 초기화 실패를 Journal에 기록할 수 있으며 이 플랫폼 기록까지 숨기지는 않습니다.

## 개발자 준비

- Windows 64비트와 Python 3.12 또는 3.13, MT5의 MetaEditor가 필요합니다. 일반 MetaTrader 5 설치 위치와 Windows 등록 정보에서 MetaEditor를 찾습니다. 별도 설치라면 빌드 실행 환경의 `MOSES_METAEDITOR`로 지정할 수 있습니다.
- 필요한 빌드 패키지를 별도 `.buildenv`에 자동 설치하고 사용이 끝난 뒤 정리합니다. 받는 사람에게 Python 설치나 인터넷 다운로드를 요구하지 않습니다.
- WebView2는 [Microsoft 공식 다운로드](https://developer.microsoft.com/en-us/microsoft-edge/webview2)의 Evergreen Standalone x64 설치파일을 자동 다운로드하고 Microsoft 서명을 확인한 뒤 Setup에 넣습니다. 받는 PC에 WebView2가 없으면 통합설치가 설치합니다. 개발자 PC에서는 이 설치파일을 실행하지 않습니다.
- 라이선스 서명키는 `통합설치/.keys`에 보관합니다. 개발자 프로젝트에서만 보관하고 받는 사람에게는 최종 Setup EXE만 전달합니다.
- `.keys`의 배포 이력도 다음 수정본에 함께 보관합니다. 원본 MT5 소스가 같은 배포본끼리는 기간을 갱신해도 기존 백테스트 녹화 자료를 재사용할 수 있도록 배포 복사본의 호환 목록에 등록합니다. 원본 MT5 소스가 달라진 경우에는 자동으로 호환시키지 않습니다.
- 다음 수정본으로 옮길 때 세 준비 폴더를 복사할 필요가 없습니다. `.buildtmp`는 잠금·실행 결과를 위한 작은 폴더입니다. 다른 컴퓨터에서는 Python과 MetaEditor를 설치한 후 배포 도구를 실행합니다.

## 원본 보존과 다음 수정본

배포 도구는 실행한 수정본 폴더의 프로그램과 매뉴얼을 읽어 새 배포물을 만듭니다. 다음 수정본으로 도구와 매뉴얼 폴더를 함께 옮겨 실행하면 그 수정본의 코드와 매뉴얼을 사용합니다. EA·지표의 이전 EX5를 재사용하지 않습니다. 폴더 번호와 배포 버전은 별도로 지정합니다.

현재 코드의 import를 따라 새 내부 모듈과 외부 라이브러리의 하위 모듈을 수집합니다. 도움말은 서버의 문서 목록에서, 웹 자산은 현재 파일과 HTML·CSS·JS 참조에서 읽습니다. 필수 라이브러리나 문서가 없으면 빌드를 중단합니다. 설치에 필요한 빈 폴더도 ZIP에 포함합니다.

컴파일 후에는 별도 임시 복제본에서 실제 배포 EXE의 라이브러리 로딩, 로컬 화면·도움말 요청, 숨겨진 WebView의 라이브 카드·백테스트·설정·Part3 전략 목록 화면을 검사합니다. 생성·승급·이름 변경·파트별 제외·재승급·삭제 확인·리셋 흐름과 개발자 테스트 전략 제외도 확인합니다. 실패하거나 확인 결과가 없으면 최종 통합설치 파일을 만들지 않고 개발자 창에 원인을 표시합니다. 검사 결과는 해당 빌드의 `검증결과/license96/<빌드번호>/release_validation.json`에 저장합니다. 검사에 사용하는 파일과 임시 라이선스는 배포본에 포함하지 않습니다.

이 검사는 배포 생성 때만 실행합니다. 사용자의 프로그램 실행·백테스트 반복 계산에는 추가하지 않습니다. 설치파일 유효시간은 이 검사와 컴파일, 최종 복사가 모두 끝난 뒤부터 시작합니다. 임의의 미래 기능 전체를 검증하는 것은 아니며 새 실행 흐름을 추가할 때에는 그 기능의 검사도 함께 추가해야 합니다.

기존 Python·MQ5·MQH와 전략 계산 로직은 수정하지 않습니다. Python 소스는 컴파일된 코드 묶음으로, MT5 소스는 별도 빌드 복사본으로 처리합니다. 배포 설정에 포함된 개인 토큰과 개인 작업 상태는 배포 복사본에서 제외합니다. AI 모델·Ollama 프로그램은 포함하지 않습니다.

기존 `통합설치.bat`, `build_release95.py`, 구형 설치 스크립트와 안내서는 처음에 이전방식 폴더에 보관했고, 이후 사용자 요청으로 삭제했습니다. 현재 배포 생성 진입점은 **모세의지팡이 배포.cmd 하나**입니다. 개발자용 기존 실행 스크립트가 쓰는 `launch.ps1`과 `common.ps1`은 보존했습니다.

더블클릭하면 준비용 PowerShell 창은 설정창을 띄운 뒤 닫힙니다. **모세의지팡이 배포** 창이 남아 있으면 정상입니다. 설정창을 실행하지 못하면 오류 메시지를 표시하며 실행 로그는 `통합설치/.buildtmp`에 남습니다. 개발자 점검은 `"모세의지팡이 배포.cmd" -CheckOnly`로 실행할 수 있습니다.

기존 개발자용 EX5로 만든 녹화 자료를 새 라이선스 EX5와 임의로 같은 빌드로 승인하지는 않습니다. 기존 원본의 명시적 호환 그룹은 보존합니다. 자료가 삭제되지는 않으며, 승인 그룹에 없는 녹화 자료는 기존 백테스트의 검사 규칙에 따라 새 녹화가 필요할 수 있습니다.

## 보호 범위와 확인한 한계

라이선스 검사는 각 프로세스 시작 때 한 번 수행하며 매 틱·매 봉의 계산에는 추가하지 않습니다. MT5 검사는 OnInit에서만 실행합니다. 설치한 EXE는 실행할 때마다 압축을 풀지 않습니다.

서버 없이 PC 시계를 사용하므로 시간을 되돌리는 우회는 막지 않습니다. 설정한 시간 안에 여러 PC에 설치하는 것도 허용됩니다. 원본 소스 파일을 배포하지 않지만 컴파일된 코드는 역분석이 가능합니다. 일반적인 폴더 복사와 만료 제한을 위한 방식입니다.

이 컴퓨터에서의 테스트 결과는 `검증결과/license96`에 저장합니다. Python이 전혀 없는 다른 Windows PC에서의 최종 설치·WebView2 자동 설치와 실제 두 PC 간 복사 차단은 별도 실기 확인이 필요합니다.
