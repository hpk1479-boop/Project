# 정식 스페셜 관리

이 폴더에 있는 `SPECIAL1`~`SPECIAL999` 정의만 새 배포본의 스페셜 전략으로 포함됩니다. 파일을 줄이면 다음 배포본의 목록도 줄어듭니다.

기존 기본 전략은 `SPECIAL번호.recipe.json`으로 보관합니다. 계산 조건은 기존 전략 정의와 같습니다.

파트3에서 만든 전략은 `Part3/TEST_SPECIAL`에 보관합니다. 메인 전략 승급은 사용 등록이며 배포 대상에 추가하는 동작은 아닙니다.

테스트 전략을 정식 배포하려면 다음 순서로 진행하세요.

1. `Part3/TEST_SPECIAL/Test_SPECIAL번호.py`를 이 폴더로 **복사**합니다.
2. 중복되지 않는 파일명으로 변경합니다. 예: `SPECIAL8.py`.
3. MOSES를 다시 실행하여 정식 스페셜 목록과 조건을 확인합니다.
4. `모세의지팡이 배포.cmd`를 실행합니다.

동일 번호의 `.recipe.json`과 `.py` 파일을 함께 두지 마세요. `.py`는 프로그램이 생성한 `PART3_RECIPE` 정의가 있는 파일을 사용합니다. 임의의 Python 전략 코드를 실행하여 읽는 방식은 지원하지 않습니다.

테스트 스페셜 폴더와 개발자의 승급·목록 제외 상태는 새 배포본에 포함되지 않습니다. 배포받은 사용자가 직접 만든 테스트 전략과 설정은 업데이트 시 보존됩니다.
