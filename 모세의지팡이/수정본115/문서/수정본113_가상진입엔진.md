# 수정본113 가상진입 엔진

## 변경 범위

시장 알림을 만든 뒤 실행하는 Part2 가상진입을 하나의 공통 정책으로 통일했습니다. 전략의 원래 조건·알림 발생 판정은 이 모듈에서 바꾸지 않습니다. 개발본과 배포본이 같은 정책 검증·Fact·진입·결과 계산 코드를 사용합니다.

- `virtual_contract.py`: UI·AI·시나리오 공통 정책, 입력 검증, 자동 기본값.
- `virtual_facts.py`: 해당 시점에 알려진 녹화 자료만 잘라서 공통 Fact에 전달하고 계산 결과를 공유.
- `virtual_rules.py`: 봉 방향·선택 조건·ATR 제한·손절 평가.
- `virtual_entry.py`: 알림별 대기·진입·만료·독립 손익비 실험과 CSV 출력.
- `indicator_facts.py`: 가변 기간 MA·ATR을 등록된 공통 Fact로 재사용.
- `analytics.py`: 새 결과 상태와 순서 미확정 결과를 같은 성과 집계 경로로 처리.

기존 HMA6/17 차이 추적, 역교차 시 진입 취소, `PASS_CROSS`·`pass_cross` 전용 결과 경로는 제거했습니다. HMA6은 올존 자동 설정에 들어가는 일반 `MA_POSITION` 조건의 기본값입니다. 별도의 6헐 진입 알고리즘이나 예외는 없습니다.

## 진입과 확인 조건

- `IMMEDIATE`: 알림의 실제 `signal_price`와 `time_ms`로 진입합니다. 봉 중간 알림에 가격이 없으면 과거 시가를 대신 사용하지 않고 오류를 안내합니다. 정확한 1분봉 시가 경계의 알림만 그 시가를 직접 사용할 수 있습니다.
- `CONFIRM`: 매수는 직전 확정봉 양봉, 매도는 직전 확정봉 음봉이어야 합니다. 도지는 통과하지 않습니다. 추가 조건을 만족하면 현재 봉 시가에 진입합니다.
- `AUTO`: 올존은 공통 확인 진입과 HMA6 위치 조건, 다른 신호는 즉시 진입을 선택합니다. 사용자 확인 조건을 지정하려면 `CONFIRM`을 선택해야 하며, 자동·즉시 모드에서 확인 조건을 조용히 무시하지 않습니다.

선택 조건은 모두 AND로 조합합니다. 각 조건을 빼면 해당 제약이 적용되지 않습니다.

| 조건 | 적용 의미 |
| --- | --- |
| `MA_POSITION` | 현재 진입 시가가 선택한 이평 위(매수) 또는 아래(매도). 직전 종가가 이평 위·아래인지 추가하지 않음. |
| `MA_CROSS` | 직전 확정봉 종가가 선택한 이평을 방향에 맞게 돌파. |
| `MA_TOUCH` | 알림 이후 확정봉에서 이평을 터치한 뒤, 별도의 후속 확인봉이 마감. 터치봉 자체 마감만으로 진입하지 않음. |
| `ENGULFING` | 직전 확정봉 몸통이 앞선 반대 방향 봉 몸통을 감싸는 상승·하락 인걸핑. |
| `NECKLINE_BREAK` | 알림을 발생시킨 해당 올존 넥라인을 확정 종가로 돌파. 다른 패턴의 최신 넥라인으로 대체하지 않음. |

MA 종류는 SMA·EMA·WMA·HMA, 기간과 프레임은 정책으로 지정합니다. 이미 EA가 공급하는 고정 MA 값은 그대로 사용합니다. 기존 공통 정의대로 EMA는 CLOSE, 다른 가변 MA는 OPEN 기준입니다. 판정 시점의 진행 EMA는 직전 확정 EMA와 이미 알고 있는 현재 가격으로 평가하므로 상위 프레임·봉 중간 진입에서도 미래 종가를 사용하지 않습니다.

## ATR 제한과 손절

- 봉 크기: 직전 확인봉 몸통(`BODY`) 또는 고가~저가(`RANGE`)를 확정 ATR로 나눔.
- 이평 거리: 현재 시가 또는 즉시 알림 가격과 선택한 이평의 거리를 확정 ATR로 나눔.
- 최소 배수는 포함, 최대 배수는 제외입니다. 예: 최대 2이면 ATR 2배 이상에서 진입하지 않습니다.
- ATR 프레임·기간, 이평 프레임·기간을 지정할 수 있습니다.
- 손절: 해당 올존 B0 / 직전 N개 확정봉 최저·최고가 / 확정 ATR × 배수.
- 올존 자동 손절은 해당 B0, 다른 신호의 자동 손절은 ATR 1배입니다. 손절이 진입가의 잘못된 방향이거나 거리가 0이면 위험 폭이 없는 진입으로 제외합니다.
- 손익비 1.0부터 5.0까지 0.5 단위의 기존 9개 실험과 스프레드·동시 손절 우선 판정은 유지합니다.
- `SIGNAL` 프레임은 원본 알림의 `signal_tf`(실제 바인딩된 가장 낮은 전략 프레임), 없으면 명시된 `tf`를 사용합니다.

## 올존 유효기간

올존은 원래 패턴 설정에서 산출한 남은 실제 봉 수를 `oz_validity`로 받습니다. 원본 기준봉 이후 새 봉 수가 남은 수를 **초과**하면 `EXPIRED`가 되며 경계의 봉에서는 진입할 수 있습니다. 분 수로 바꾸지 않으므로 주말·휴장 시간이 대기 만료를 앞당기지 않습니다. 다른 신호에는 올존 유효기간을 적용하지 않습니다.

출처·올존 원본 유효기간·선택한 넥라인 정보가 필요한데 없으면 명시적으로 오류를 안내합니다. B0 가격만 보고 올존으로 추측하거나, 오래된 CSV의 불명확한 신호를 일반 신호로 가정하지 않습니다.

진행·등록·취소 안내는 `NOTICE`로 구분합니다. 부모 문맥의 TF·방향이 포함되어 있어도 가상진입 알림으로 취급하지 않습니다.

## 봉 자료의 가격 순서

완료된 1분봉만 손절·익절에 사용합니다. 봉 중간 즉시 진입의 첫 1분봉이 어떤 손익비의 손절 또는 목표에 닿았어도, 그 가격이 진입 전인지 후인지 OHLC만으로 알 수 없습니다. 그 손익비 결과는 `UNCERTAIN`(순서 미확정), R은 비어 있는 값으로 확정하며 이후 봉으로 승패를 만들어 내지 않습니다. 접촉하지 않은 다른 손익비는 다음 봉부터 정상 평가합니다.

성과 집계에서 `uncertain`은 승·패·미청산과 구분합니다. 실제 진입 수에는 포함하되 승률·평균 R·누적 R·손익 곡선에서 제외합니다. 개발본·배포본의 공통 성과 표에서 같은 의미로 표시합니다.

## 검증

`검증결과/revision113/core/pytest.xml`의 관련 최종 회귀 164개가 통과했습니다.

- 양봉·음봉·도지, 선택 이평을 뺀 진입, 직전 종가의 불필요한 이평 제약 없음.
- 기존 HMA6/17 역교차 예외 제거와 자동 설정·명시 공통 설정의 같은 결과.
- 이평 돌파·터치 후 후속봉 확인·인걸핑·원본 올존 넥라인.
- ATR 최소·최대 경계, 몸통·전체 봉·이평 거리, 손절 방향과 직전 N봉.
- 원본 실제 봉 수 유효기간, 주말 간격과 경계, 비올존에 임의 만료 없음.
- 가변 MA·ATR와 기존 순수 수식 일치, 형성봉 미래 종가 배제, 상위 프레임·즉시 진입 EMA 현재 가격 반영.
- 실제로 생성한 MSD1, MSD2 미공개·공개 녹화의 FULL·ROW·HEARTBEAT 읽기와 결과 CSV, 폴더 이동.
- 봉 중간 첫 1분봉의 손익비별 순서 미확정 집계와 원래 9개 손익비·동시 손절 우선·스프레드·독립 완료·취소 경로.

실제 MT5나 텔레그램으로 주문·발송하지 않았고 사용자 데이터창고는 수정하지 않았습니다.
