# 수정본111 설치 완료 처리와 MT5 파일

설치·업데이트 성공 시 `설치 성공 → 설치 창 자동 종료 → 실행한 통합설치 EXE 삭제` 순서로 처리합니다. 설치 실패, 설치 전 창 닫기, 유효시간 만료는 성공으로 취급하지 않으며 통합설치 파일을 삭제하지 않습니다.

완료 뒤 수동으로 창을 닫거나 프로그램 실행 버튼을 누르는 흐름은 제거했습니다. 완료 시 바로 창을 닫고 설치 폴더의 `MOSES.exe`로 실행합니다. 완료 후 실행 버튼과 설치 위치 보관 필드, 수동 창 닫기 안내 문구도 제거했습니다.

자동삭제는 설치 창이 닫힌 뒤에만 예약되며, 숨김 보조 프로세스가 해당 설치 프로세스의 종료를 기다립니다. 실행한 EXE의 경로·길이·SHA256을 확인하므로 같은 위치에 다른 파일이 놓였거나 옆에 다른 설치파일이 있어도 지우지 않습니다. 일시적인 읽기·삭제 잠금은 최대 60초 재시도합니다. 권한 거부나 계속되는 잠금은 설치 성공을 실패로 되돌리지 않으며 설치 EXE가 남을 수 있습니다.

배포 payload와 설치 폴더 바로 아래 `MT5`에는 다음 EX5 5개가 있습니다.

- `THE_STAFF_OF_MOSES.ex5`
- `PRICE_of_Moses.ex5`
- `RSI_of_Moses.ex5`
- `STO_of_Moses.ex5`
- `DI_of_Moses.ex5`

모두 이번 배포에서 지정한 만료일로 원본의 별도 복사본을 새 컴파일한 파일입니다. 내부 `Part1/program/MT5`와 동일한 바이트를 포함합니다. 내부 경로는 백테스트·호환 검사에서 계속 사용하므로 유지합니다. MT5 자동복사와 업데이트는 기존처럼 EA를 `MQL5/Experts`, 네 지표를 `MQL5/Indicators`에 배치합니다. 루트의 `MT5`는 직접 복사할 때 사용합니다.

배포 검사는 루트 `MT5`에 정확히 다섯 파일이 있으며 내부 licensed EX5와 같은지 검사합니다. 누락·추가 소스·다른 EX5·빈 파일은 최종 통합설치 발급 전에 차단합니다. 업데이트에서 루트 MT5 파일도 설치 관리 파일로 등록되어 새 배포 파일로 교체됩니다.

매뉴얼의 설치 완료·수동 MT5 복사 안내와 종료 안내를 갱신했습니다. 다른 파트의 사용법과 전략 설명은 유지했습니다. 매뉴얼은 25쪽이며 4·5·19쪽 렌더링에서 잘림·겹침 없이 확인했습니다.

검증 증거는 `검증결과/revision111/installer`에 있습니다.

- 최종 회귀 196개와 추가 읽기 잠금 후 삭제 검사 1개 통과, 하위 검증 107개 통과.
- Windows C# 템플릿 실제 컴파일 후 격리된 설치·업데이트 성공의 자동 창 종료와 자기 EXE 삭제 확인.
- 실패·취소 시 창/EXE 유지, 유효시간 만료 시 무창 종료 및 EXE 유지 확인.
- 임시 잠금 해제 뒤 삭제, 다른 설치파일 보존, 길이가 같은 교체파일 보호 확인.
- 실제 MetaEditor로 EX5 5개 컴파일, 원본 MT5 파일 해시 불변 및 루트/내부 EX5 일치 확인.
- 다음 버전의 변경된 입력을 사용하는 빌드 경로, 수동 복사 파일 누락/변조 차단, 설치 업데이트/롤백/매뉴얼 최신 포함 회귀 확인.

전체 용량의 최종 통합설치 EXE는 생성하지 않았습니다. 검증에 사용한 컴파일 복사본·임시 설치 폴더·부분 ZIP은 결과를 남긴 뒤 정리했습니다. 개발자 원본 MQ5·MQH·EX5 및 이전 수정본110은 이 작업에서 수정하지 않았습니다.
