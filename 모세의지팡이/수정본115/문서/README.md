# 문서 안내 — 수정본66

프로젝트 최상위의 누적 문서를 이 폴더로 정리했다. 문서마다 작성 당시 수정본과 상태가 다르므로 현재 동작은 실제 코드와 현행 작업 규칙으로 확인한다.

수정본66은 65의 통합 웹 UI를 유지하면서 우선순위 1·2번(설정 손상 차단·백테스트 시작 직전 취소)과 후속 3·4번(엔진 정상 종료·저장 확인·중복 실행 확인·실제 준비 판정)을 처리했다. 기록은 [수정내역_시작차단과백테스트취소66.md](작업이력/수정내역_시작차단과백테스트취소66.md), [수정내역_엔진정상종료와중복시작66.md](작업이력/수정내역_엔진정상종료와중복시작66.md)에 있다.

수정본65는 64의 계산·공식 연결 API·대시보드를 유지하면서 Part1·Part2 개별 GUI를 통합 웹 UI로 정리했다. 당시 실행과 변경 기록은 [수정내역_웹UI통일65.md](작업이력/수정내역_웹UI통일65.md)에 있다.

수정본64는 문서 정리가 끝난 수정본63에 수정본62의 공식 연결 API를 병합했다. 현재 병합 기록은 [수정내역_병합64.md](작업이력/수정내역_병합64.md), 연결 API의 원래 작업 기록은 [수정내역_Part3공식연결API62.md](작업이력/수정내역_Part3공식연결API62.md)에 있다. 수정본63 보고서의 “62 미포함” 설명은 당시 상태이며 수정본64에는 해당 변경이 포함된다.

## 유지한 연결 문서

AGENTS/CLAUDE 규칙, 현재 실행·검증 안내, Part3의 AI 프롬프트·웹 도움말 및 각 하위 폴더의 실행 안내는 현재 경로를 유지했다. 가상환경·패키지 라이선스·검증결과는 정리 대상에서 제외했다.

이동한 문서의 일반 Markdown 링크는 새 위치에서 같은 대상을 가리키도록 조정했다. 본문의 백틱 경로는 원래 프로젝트 루트 기준 표기를 유지한다. 과거 build 보고서 생성 도구는 옛 문서 경로를 포함하며 현행 공식 검증에 사용되지 않는다.

현재 수정본으로 복사되지 않은 과거 검증결과 링크는 원래부터 없는 자료다. 새로 만든 검증결과로 대체하지 않았다.

전체 이전/현재 경로와 해시는 프로젝트의 `검증결과/문서정리63/organization.json`에 기록했다.
