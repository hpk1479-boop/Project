# 수정본59 — 직전 intent를 기준으로 전략 대화 수정

2026-10-01. 수정본58을 복사해 수정본59에서 작업했다. 이전 검증결과와 Python 캐시는 복사하지 않았다. 이번 증거는 `검증결과/수정형대화59/`에 저장했다.

## 동작

AI Agent는 schema 검증을 통과한 최신 전체 canonical intent를 대화 세션에 보관한다. 그 이후의 문장은 해당 intent를 기준으로 수정하는 요청으로 전달한다. 매 요청에 최신 intent JSON을 명시적으로 전달하고, 요청하지 않은 항목은 유지하며 전체 JSON을 반환하도록 한다. 시간봉을 자연어 정규식으로 고치거나 특정 예제 문장을 코드에서 분기하지 않는다. 기존 system prompt와 모델의 출력 schema는 유지했다. 후속 요청에 필요한 짧은 안내와 상태 전달만 추가했다.

수정 결과 전체를 기존 `validate_intent`로 다시 검증한다. 부분 JSON·지원하지 않는 시간봉·지원 범위 밖 결과·연결 실패는 적용 후보를 제거하며 마지막 검증된 intent는 보관한다. 모호한 요청은 기존 clarification 흐름으로 질문하고, 답변 후 다시 전체 결과를 표시한다. 취소나 Part3 적용 후에도 대화 상태를 유지하므로 같은 전략을 더 수정할 수 있다. 다른 전략은 ‘대화 새로 시작’을 누른다. 상태는 현재 서버의 대화 세션 메모리에 있으며, 기존 모델 설정 저장의 세션 초기화 방식은 변경하지 않았다.

수정 요청을 보내면 기존 미리보기와 생성 가능 상태를 비운다. 요청 처리 중 확인·취소·새 대화와 중복 전송을 잠근다. 새 해석을 확인하고 ‘해석 확인 후 적용’을 눌러야 Part3 미리보기와 초안 저장이 진행된다. 전략 파일은 그 이후 별도의 ‘전략 파일 생성’ 버튼으로만 만든다. API 응답의 대화 revision 번호와 확인 요청의 번호가 다르면 적용을 거절한다. 같은 세션의 수정과 적용은 잠금으로 직렬화한다. revision은 응답 봉투에만 추가했고 canonical intent와 Recipe 형식은 변경하지 않았다.

## 요청한 흐름의 시험 결과

실제 Edge 화면 → 인증된 로컬 Part3 HTTP → 시험용 모델 응답 → 임시 저장 폴더를 연결했다. 라이브 상태 폴링만 대체했고 AI 대화·확인·미리보기·초안·생성은 실제 서버 경로를 사용했다.

| 단계 | 입력 / 결과 | 저장 상태 |
|---|---|---|
| 최초 해석 | “15분 상승추세일 때 3분 하단 원비 터치하면 1분 일반 브레이커를 감시해” → TREND 15m, WONBI_TOUCH 3m | 초안 없음, 전략 파일 0개 |
| 수정 요청 | “아니 원비는 15분이야” → 직전 전체 canonical intent와 함께 provider에 전달 | 자동 적용 없음 |
| 수정된 intent | WONBI_TOUCH의 tfs만 `["3m"]`에서 `["15m"]`으로 변경. 추세·방향·종목·관계·시간·최종 행동·반복 여부는 그대로 유지 | 전체 schema 재검증, 초안 없음, 전략 파일 0개 |
| 사용자 재확인 | 수정된 전체 한국어 해석과 상세 JSON을 표시. 이전 revision의 확인 요청은 HTTP 400으로 거절 | 새 해석 확인 대기 |
| Part3 적용 | ‘해석 확인 후 적용’ → 수정된 intent를 포함한 Recipe v2 미리보기 / 초안 | 전략 파일 0개 |

추가로 적용 후 “감시 시간만 2분으로 바꿔” 요청을 시험했다. 최신 15m 원비 intent를 기준으로 final_window_sec만 600→120으로 변경했다. 다시 확인하기 전에는 기존 생성 버튼이 잠기고, 재확인 후 별도 생성 버튼을 눌러 임시 폴더에 전략 파일 1개를 만들었다. 기존 프로젝트의 generated 파일과 사용자 설정은 쓰지 않았다.

검증된 수정 intent의 주요 내용:

```json
{
  "direction": "LONG",
  "symbols": ["XAUUSD+"],
  "steps": [
    {"kind": "TREND", "tfs": ["15m"], "direction": "LONG", "bar_state": "CLOSED"},
    {"kind": "WONBI_TOUCH", "tfs": ["15m"], "side": "LOWER", "direction": "LONG"}
  ],
  "order_mode": "SIMULTANEOUS",
  "global_combine": "ALL",
  "within_sec": null,
  "final_window_sec": 600,
  "persistent": true,
  "final": {"kind": "OZ", "tfs": ["1m"], "validation_mode": "NORMAL", "trigger_mode": "BREAKER"}
}
```

위 객체는 전체 결과의 interpretation이다. supported/intent/needs_clarification 등을 포함한 전체 canonical 응답과 단계별 상태는 `ui_flow.json`에 보존했다. 화면 증거는 `revised_intent.png`, `confirmed_preview.png`이다.

Qwen 실모델의 문장 해석 품질 시험이나 추가 프롬프트 튜닝은 수행하지 않았다. 시험용 응답으로 상태 전달·전체 검증·재확인·적용과 생성 차단 기능을 검증했다.
