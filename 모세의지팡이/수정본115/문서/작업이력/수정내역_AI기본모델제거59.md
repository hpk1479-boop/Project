# 수정본59 — AI 모델 기본값 제거

2026-10-01. 수정본59에서 이어서 작업했다. 증거는 `검증결과/AI기본모델제거59/`에 저장했다.

`Part3/lab/ai/provider.py`의 `DEFAULT_MODEL`을 `None`으로 바꿨다. `from_settings()`는 `settings.get('model')` 값만 사용한다. 설정이 없거나 null·빈 문자열·공백이면 `RuntimeError('AI 모델이 설정되지 않았습니다.')`로 중단한다. provider를 직접 만들 때도 모델명이 없으면 같은 오류를 낸다. 모델이 없는 상태에서는 Ollama AI 호출을 하지 않는다.

설정 읽기 API는 모델 미설정을 `model: null`로 반환한다. 이 상태에서도 설정 화면을 열어 모델 목록을 조회하고 선택·저장할 수 있다. 드롭다운에 ‘모델을 선택하세요’를 표시하며 목록 첫 모델을 자동 선택하거나 저장하지 않는다. 대화 연결 안내도 미설정 상태를 한국어로 표시한다. Ollama 조회 실패 시 수동 모델명 입력은 유지한다.

처음 저장할 때는 모델을 지정해야 한다. 지정 후 응답 대기 시간만 변경하면 이미 저장한 모델을 유지한다. 기존 사용자의 저장 모델을 삭제하거나 바꾸지 않았다. 모델 외의 기존 연결 주소·응답 대기 시간·schema·think·stream 옵션은 유지했다.

제품 파일 4개 수정:

- `Part3/lab/ai/provider.py`: 기본 모델 제거, 미설정 호출 차단.
- `Part3/lab/server.py`: 저장된 모델만 읽기, 미설정 상태 조회 허용.
- `Part3/web/ai_chat.js`: 모델 미설정 안내.
- `Part3/web/unified.js`: 미설정 선택 안내와 자동 선택 방지.
