## 2. 핵심 수정 내용

### 현재 실행·명령·UI·신규 저장

현재 OZ 어휘는 아래 네 조합뿐입니다.

| 검증 모드 | 트리거 | 표시명 |
|---|---|---|
| NORMAL | OZ | 올존 |
| BLIND | OZ | 무지성 올존 |
| NORMAL | BREAKER | 브레이커 올존 |
| BLIND | BREAKER | 무지성 브레이커 올존 |

`oz_profiles.py`에서 과거 프로필 차단 목록, 전용 거부 함수, 실행 중 별칭 변환을 제거했습니다.
명령 해석에서는 현재 어휘를 사용하는 OZ 명사구만 파싱하며, 알 수 없는 수식어는 일반 문법 오류로 처리합니다.
명령 방향 파서의 특정 과거 단어 제거 코드도 삭제했습니다. 현재 명령·UI·AI 안내에는 과거 프로필을 별도 기능으로 취급하는 경로가 없습니다.

Part1·Part2·Part3의 현재 설정 저장, Recipe/프로젝트/초안 저장, 수동 생성 코드의 프로필 리터럴 검증을 연결했습니다.
잘못된 프로필은 파일을 새로 쓰기 전에 오류로 반환됩니다. 콤보박스의 코드 기본값은 전략의 현재 네 조합 중 기본값을 뜻하며 별도 프로필이 아닙니다.

### 저장파일 로드 경계

구버전 문자열 해석은 신규 `Part1/program/oz_profile_loader.py`의 단일 공개 진입점 `load_saved_oz()`에 모았습니다.
각 파일 로더는 이 진입점을 호출한 뒤 현재 스키마에 전달합니다. 명령·새 설정 검증기는 이 호환 변환을 호출하지 않습니다.

| 저장 데이터 | 로드 결과 |
|---|---|
| DIVERGENCE | BREAKER로 읽기 변환, 나머지 실행 상태 보존 |
| REGIME / SUPER 및 조합 | `LegacyUnsupportedProfile`로 해당 설정 제외, 원본·경로·사유 보고 |
| 미지원 SPECIAL 설정 | `enabled=False`, `load_error`, `original`로 보고하며 기본 프로필을 채우지 않음 |
| 미지원 Watch/Chain/후보 상태 | 기존 격리·오류 보고 경로에 원본 보존, 실행 대상에서 제외 |
| 미지원 Part3 Recipe/초안/생성 코드 | 불러오기 또는 실행 이전에 오류 보고, 원본 파일 덮어쓰기 없음 |

UI에서 제외된 항목은 프로필 재선택이 필요하다고 표시합니다. 사용자가 명시적으로 현재 프로필을 선택하기 전에는 그 항목을 기본값으로 저장하지 않습니다.
저장된 Python 코드의 호환은 AST로 OZ 프로필 리터럴만 확인하며, 허용되는 별칭 변환도 메모리 안에서만 수행합니다.

### SPECIAL5·SPECIAL7 및 보존 범위

SPECIAL5에서 과거 OZ 프로필 전용 Watch 식별·정리·변환 코드를 제거했습니다.
현재 상위 `NORMAL/BREAKER + 확정봉 EMA50/200` 경로는 유지했습니다. 별도 레짐 후보, 레짐밴드 대체 OZ, 추가 B0 상태나 계산기를 만들지 않았습니다.
SPECIAL7 원본은 수정하지 않았으며 `15분 TREND → 1분 NORMAL/BREAKER` 기본 정의를 검증했습니다.

수정본49의 범용 MA 기간, `MA_EXPRESSION` TimedChain, 교차 기본 `CLOSE`, 저장·복원·단계 진행·취소 동작은 유지했습니다.
MA 계산기, WatchMAStore가 있는 파일, WatchMonitor 이벤트 경로, 공용 지표 계산기, SPECIAL1/2/3/4/6/7, 명령 별칭 JSON, MT5 EA는 수정본49와 바이트 단위로 같습니다.
기존 Part3 생성 파일 17개와 reference 파일 156개도 원본 그대로 보존했습니다. 구버전 생성 파일의 미지원 프로필은 로드 단계에서 실행을 막습니다.
검사 근거는 `검증결과/OZ50/static_integrity.json`에 있습니다.

### 통과로 집계하지 않은 기존 진단·환경 의존 검사

**저장소 전체 테스트가 전부 통과한 상태는 아닙니다.** 최종 전체 수집은 DuckDB 미설치로 5개 모듈에서 오류가 발생했습니다.
해당 5개 모듈의 수집 오류를 제외한 검사 중 아래 22건은 현재 환경에서 실패하며, 수정본49에서도 재현됩니다.

| 분류 | 건수 | 사유 |
|---|---:|---|
| 데이터베이스·백테스트 저장 계층 | 16 | DuckDB 미설치 |
| Windows 네이티브 IPC | 4 | Linux 환경의 WinDLL/AF_PIPE 미지원 |
| 과거 수정본 바이트 비교 | 2 | 수정본26·수정본34 파일 미제공 |

별도 과거 MA 진단에서는 기록 파일의 `EMA21` 키 누락으로 1건 실패하고, 이미 없는 `strategy_TREND.py`를 요구하여 15건 오류가 발생했습니다.
수정본49에도 같은 MA 진단을 실행하여 **1건 실패·172건 통과·15건 오류**가 동일함을 확인했습니다. 삭제된 모듈을 복원하거나 기대값을 바꾸지 않았습니다.
DuckDB 설치를 시도했으나 이 환경에서는 설치 가능한 배포본을 찾지 못했습니다.

확대 검사의 28건 deselect는 기존 `pytest.ini`의 6건과 이번 실행 환경 의존 22건입니다. `pytest.ini`는 수정하지 않았습니다.
이번 요구사항 때문에 계약이 바뀐 기존 테스트만 저장 로드 경계로 옮기거나 현재 프로필 입력으로 갱신했고, 수정본49의 MA·TimedChain 테스트 원본은 그대로 실행했습니다.

### 증거 파일

`검증결과/OZ50/targeted_final.log/.xml`: 최종 대상 회귀.
`all_available.log/.xml`: 실행 가능한 확대 회귀.
`ma_contract_all.log/.xml`와 `baseline_ma_diagnostics.log/.xml`: 기존 MA 진단 및 수정본49 재현.

재실행은 프로젝트 루트에서 `python -m pytest -q`로 할 수 있습니다. 모든 환경 의존 검사를 실행하려면 DuckDB, Windows 네이티브 IPC 및 해당 과거 비교 파일이 필요합니다.
현재 환경에서의 확대 검사 제외 목록은 `environment_exclusions.json`에 명시했습니다. 새 테스트의 주요 실행 명령은 `python -m pytest tests/test_oz_profile_boundary50.py tests/test_ma_strategy_chain49.py -q`입니다.
