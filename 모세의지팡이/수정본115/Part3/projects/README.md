# 프로젝트 설정과 초안

설정 저장 JSON과 `last_draft.json`, 연결을 저장한 `connections.json`이 들어갑니다. 배포본은 사용자의 연결 경로와 초안을 비워 두었습니다.

설정 JSON에는 기준 원본 source_text와 카드 설정이 들어 있습니다. `_loaded_slots` 등 비교 기준 필드를 현재 슬롯으로 덮어쓰지 마세요. UI의 원본 보존 분기가 그 값을 사용합니다.

수동 코드 편집 초안에는 수동 Python도 포함됩니다. 정식 보존은 전략 파일 생성으로 새 Test 파일을 만드세요. 외부 공유 전 로컬 경로와 사용자 메모를 확인하세요.
