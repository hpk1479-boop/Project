- BACKTEST가 LIVE의 FVG / TREND / ALLZONE(OZ) 계산 코어를 직접 재사용한다.

FVG
- BACKTEST의 별도 FVG 수식 복제를 제거하고 실제 LIVE strategy_FVG 함수 객체를 직접 재사용.
- 기존 BACKTEST 구현과 랜덤/강제 gap fixture 비교: 수치/zone/fill exact parity 통과.
- LIVE 파일 수정 없음.

TREND
- BACKTEST가 LIVE strategy_TREND.TrendEngine의 score/evaluate/metric_snapshot 계산 메서드를 직접 재사용.
- 네 TF/양방향/전체 metric 비교 exact parity 통과.
- LIVE 네트워크 client 생성자는 BACKTEST에서 사용하지 않음.
- LIVE 파일 수정 없음.

ALLZONE Monitor / OZ
- BACKTEST의 복제 규칙을 LIVE monitor_OZ.OZMonitor 핵심 계산/상태전이 메서드 직접 재사용으로 변경.
- historical 환경 차이는 외부유동성 watch adapter와 checkpoint persistence adapter만 분리.
- LIVE OZMonitor 생성자/실행 thread/network loop를 BACKTEST에서 실행하지 않음.
- import 시 LIVE OZ 로그를 만들거나 root logging을 설정하지 않도록 BACKTEST loader에서 import 부수효과 차단.
- Part1/program/logs/OZ_monitor.log 생성 안 됨 확인.
