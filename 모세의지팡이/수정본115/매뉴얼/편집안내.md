# 모세 트레이딩 시스템 사용자 매뉴얼 관리

받는 분에게 전달하는 매뉴얼은 이 폴더의 **모세_사용자_매뉴얼.pdf** 한 파일입니다.

표지와 PDF 제목은 **모세 트레이딩 시스템 사용자 매뉴얼**입니다. 배포 도구와 연결된 PDF 파일명은 그대로 유지합니다.

현재판은 수정본113 기준 25쪽입니다. 설치·업데이트, MT5, 텔레그램, Gemini, 파트1·2·3 사용법과 올존 트리거 네 가지를 설명합니다. 텔레그램 설정은 각 입력칸 옆의 확인 버튼으로 검사·저장합니다. 올존은 9~12쪽에 있으며, 마이크로 더블바텀의 우측 저점·더블탑의 우측 고점에서 알림이 오므로 실제 반전 확인이 필요하다는 설명과 개념도를 포함합니다. 17쪽에 공통 가상진입·ATR 제한·손절 설정, 19쪽에 올존 패턴 유효기간과 순서 미확정 결과를 추가했습니다.

1. 내용을 수정한 PDF를 이 폴더에 같은 이름으로 저장하세요.
2. 수정본 루트의 **모세의지팡이 배포.cmd**를 실행하세요.
3. 배포 설정을 정하고 **모세의지팡이 통합설치 만들기**를 누르세요.

배포 도구는 매번 실행한 수정본 폴더의 현재 PDF를 읽습니다. 이전에 만든 PDF나 이전 수정본의 경로를 재사용하지 않습니다. 설치 후에는 `MOSES/매뉴얼/모세_사용자_매뉴얼.pdf`에 들어가며, 업데이트 때 새 PDF로 교체됩니다.

PDF가 없거나 PDF 형식 표시가 손상되었으면 배포를 중단합니다. 배포를 만드는 중에는 PDF를 수정하거나 삭제하지 마세요. 원본과 배포 PDF의 용량·SHA-256을 비교하고 통합설치 ZIP에 실제 들어간 내용도 검사합니다.

`편집원본/제작.py`는 현재 매뉴얼을 만든 편집용 원본입니다. 문장과 표는 이 파일의 `add(...)` 부분에 있습니다. Python의 reportlab·pypdf가 있는 편집 환경에서 실행하면 이 폴더의 PDF를 다시 만듭니다. 제작 스크립트는 어느 수정본에서 실행해도 자기 파일 위치를 기준으로 경로를 찾습니다. 다시 만든 PDF는 글자가 잘리지 않았는지 화면에서 확인하세요.

PDF를 만들 때 페이지 넘침, 필수 내용과 이전 버튼 이름의 잔존 여부를 확인합니다. 검증이 끝난 PDF만 기존 PDF와 교체합니다. 현재 검증 기록은 `검증결과/revision113/ui/manual`에 저장됩니다. 향후 화면이나 설명을 수정하면 제작 원본의 문장과 페이지 번호 안내를 함께 갱신한 뒤 PDF를 다시 만드세요.

편집 원본과 이 안내서는 개발자 폴더에만 보관합니다. 배포본에는 PDF 한 파일만 포함됩니다. 다음 수정본으로 옮길 때 이 매뉴얼 폴더와 통합설치 도구를 함께 복사하세요.
