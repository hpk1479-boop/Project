# MT5 계산값 직접 사용 — 2026-09-25

## 실행 흐름

1. MT5가 과거 봉을 읽어 PRICE/RSI/STO/DI를 초기화하고, 선택한 측정 구간만 틱 재생한다. 준비용 seed_plan 시작일을 테스터 시작일로 사용하지 않는다.
2. 매 simulated second의 스냅샷을 `SECOND_SNAPSHOT_V1` 형식으로 기록한다. 기존의 분/상태변화 압축 기록은 직접 입력으로 사용하지 않는다.
3. Common/Files 결과를 작업 폴더 `native_mt5/export_<session>`에 복사하고 해시 검증 후 보존한다.
4. 실행 설정의 `resources.native_export`가 파일 경로·심볼·해시·기간을 전달한다.
5. Python은 봉과 평가 시각에 맞는 기록을 읽어 전략 입력으로 전달한다. PRICE/RSI/STO/DI의 Python provider와 conditional 재계산 경로는 사용하지 않는다.

Python은 선택 기간의 원시 틱 읽기, 봉 갱신, 전략 상태와 조건 판단, 필요 시 손익 평가를 수행한다. 시작 전 과거 틱을 가져오거나 재생하지 않는다. MT5의 과거 완료 봉으로 OHLC 이력을 초기화하며, 시작 시 진행 중인 상위 봉은 시작 전에 완료된 1분봉만 합쳐 만든다. 이후에 확정된 상위 봉의 고가·저가·종가를 초기값으로 사용하지 않는다. 초기 봉은 작업 폴더 bar_seed.json에 저장하고 해시·심볼·캘린더·시작 시각을 검증한다. 분 경계가 아닌 시작 시각은 이 초기화 모드에서 거부한다.

전략 감시 상태는 선택한 시작일부터 새로 생성한다. 시작 전부터 진행되던 감시 상태를 승계하는 장기간 재생과 같은 결과를 보장하지 않는다. 과거 봉의 거래량은 MT5 봉의 tick_volume이며, BID 변경 틱만 세는 원시 틱 구성 방식과 다를 수 있다. 이 초기화 정책은 UI 로그와 결과 메타데이터에 기록한다. 네 밴드를 두 번 계산하지 않는다.

## 시점과 값

- 봉마감 모드는 `CloseMarketCore`를 사용한다. 최하위 필요 시간봉이 1m이면 1분 마감, 5m이면 5분 마감에서만 전략용 상태를 만든다. 봉 내부 틱은 OHLC/거래량으로 누적하며 원시 틱의 순서와 prefix hash는 유지한다. 서로 배수가 아닌 시간봉(예: 5m/6m)의 경계도 보존한다.
- TICK과 LIVE_PARITY는 기존 매 틱 시장 상태 갱신 경로를 사용한다. TRADE의 체결/손절/목표 평가도 매 틱을 유지한다. 봉마감 모드에는 매 틱 지표 계산용 conditional replay와 수치 파일 캐시를 연결하지 않는다.
- 결과의 `metadata.market_processing`에 처리 경로, 입력 틱 수, 상태 생성 횟수를 기록한다. 세션 필터 밖에서는 봉은 갱신하되 전략을 호출하지 않는다.

- 평가 시각 이후 기록을 읽지 않는다.
- 1분봉 마감 모드에서는 막 닫힌 기준 봉과 진행 중인 상위 봉을 각각 해당 봉 ID/시각으로 찾는다.
- 지표 수치는 MT5 double 그대로 전달한다. EMPTY_VALUE는 소비 경계에서 unavailable로 처리한다.
- MT5 EA의 계산 주기는 매 틱이 아닌 매 simulated second이다. 결과 메타데이터에 이를 기록한다.
- 기존 sparse 형식, 다른 심볼, 해시 불일치, 선택 기간 누락, 지원하지 않는 사용자 지표 매개변수는 오류로 처리한다. Python 네 밴드 재계산으로 자동 대체하지 않는다.
- MT5 날짜 설정은 UTC 일 단위이므로 바깥쪽으로 반올림된다. 별도 요청의 정확한 시작/종료 초로 EA 계산·출력을 제한한다. 종료일 당일 일부 시간을 누락하지 않는다.
- 원시 틱과 MT5 계산값은 다른 입력이며, 원시 틱 자료 준비/봉 구성 시간은 남는다.

## 검증

- 실제 MT5 실행: 19개 시간봉, 4,610,578개 스냅샷, 약 51.8초. 파일 보존 확인.
- 실제 파일의 1,824개 수치를 전략용 어댑터와 비트 단위 비교: 모두 일치. Python percentile 호출 0회.
- 코디네이터 통합 검사: native 입력을 worker에 전달하고 결과 SUCCEEDED까지 확인. 이 검사는 합성 틱과 검사 전용 worker를 사용한다.
- 관련 회귀 검사: 38 passed, 1 skipped. 실제 사용자 전체 전략의 장기간 최종 결과 생성까지 실행한 검증은 아니다.
- 실행 증거: `generic_runs/part2_native_verification/result.json`, `consume_verification.json`.
- 과거 틱 워밍업 제거: 실제 MT5에서 19개 시간봉 × 681개 완료 봉과 진행 중인 6개 봉 초기화 0.93초, 과거 틱 요청 0회. `generic_runs/bar_seed_live_verification/report.json`. 전체 전략 실행 시간 측정은 아니다.
- 새 초기화 검사: 시작 이후 값 배제, 상위 진행 봉 갱신, 해시 변조 차단, 선택 기간만 담은 archive로 코디네이터 완료, GUI 선택 기간 전달을 검사한다.
