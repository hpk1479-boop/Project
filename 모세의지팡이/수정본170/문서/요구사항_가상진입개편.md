## 참고: 현재 동작 (수정본136 기준)


| 진입 방식 | 동작 |
|---|---|
| 자동 (AUTO) | 올존: 확인 진입 + 신호 시간봉 HMA6 시가 위치 조건. 다른 알림: 즉시 진입. 손절 자동은 올존이면 B0, 아니면 ATR |
| 즉시 진입 (IMMEDIATE) | 알림 시점 가격으로 진입. 추가 조건 없음 |
| 확인 진입 (CONFIRM) | 직전 확정봉이 매수 양봉 / 매도 음봉으로 마감한 뒤 현재 봉 시가에 진입. 추가 조건(이평 위·아래, 이평 종가 돌파, 이평 터치 후 확인, 인걸핑, 넥라인 종가 돌파)은 모두 만족해야 함 |

그 밖의 설정은 다음과 같다.

- ATR 필터: 봉 크기 ATR, 이평 거리 ATR, 최소·최대 배수.
- 손절: 자동 / 올존 B0 / 직전 N봉 저점·고점 / ATR 배수.
- 손익비: 1:1~1:5를 0.5 간격으로 비교.
- 스프레드 포인트.
- 순서 미확정은 승률에서 제외.
