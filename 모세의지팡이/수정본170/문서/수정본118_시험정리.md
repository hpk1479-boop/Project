## 시험이 `검증결과`를 건드리지 않게 함

- 루트 `conftest.py`: pytest 실행 때 `MOSES_EVIDENCE_ROOT`가 없으면 임시 폴더를 만들어 지정하고 끝나면 지움.
- 화면 캡처·보고서를 쓰던 시험 25개 파일(브라우저 시험 18개, 파이썬 7개)은 모두 `MOSES_EVIDENCE_ROOT`(없으면 `검증결과`)에 씀.
- 수정본의 증거로 남기려면 그 수정본의 `검증결과`를 지정해서 실행합니다.

```bash
set MOSES_EVIDENCE_ROOT=검증결과&& python -m pytest Part3/tests/test_settings_version117.py
```

- 회귀 시험 `tests/test_evidence_location118.py`: 임시 폴더가 프로젝트 밖인지, 모든 시험 파일의 증거 경로가 `MOSES_EVIDENCE_ROOT`를 거치는지 확인.

## 손대지 않은 것

- `verification/`(119개 파일, 진단용·기본 실행 밖), `Part1/audit`, Part2 `validation_suite` 등: 기본 실행 밖이라 이번 범위에서 제외.
- `Part3/tests/test_ai_guard_50.py`는 수정본 폴더 밖의 `AI 교육` 폴더를 읽습니다(경로 규칙 위반, 다른 PC에서는 실패). 시험 자료를 수정본 안으로 옮길지 결정이 필요합니다.
- `검증결과/` 바로 아래의 `moses_modularity_replay_design_D1.md/.docx`: 처음에는 수정본118 루트에 있었는데 작업 중 `검증결과`로 옮겨져 있었습니다. 제가 옮긴 기록은 없고, 내용은 그대로입니다. 위치는 정해 주시면 옮기겠습니다.
- pytest 기본 임시 폴더(`%TEMP%\pytest-of-…`)는 이 PC에서 접근이 거부되어 `--basetemp`를 짧은 경로로 지정해 돌렸습니다(긴 경로에서는 통합설치 시험 일부가 Windows 경로 길이로 실패).
