## 1. 경제지표 설정 2개 제거

`경제지표 알림 이력 파일`(`ECONOMY_ALERTED_FILE`), `경제지표 요약 저장 파일`(`ECONOMY_BRIEFING_FILE`)은 수정본119에서 옛 파일 복사 코드를 지운 뒤 아무 동작도 하지 않았습니다. 실제 기록은 `event_state` 폴더의 `economy_alerted.txt`, `economy_briefing.txt`에 저장됩니다.

| 위치 | 변경 |
|---|---|
| 설정 화면 (`Part3/web/unified.js`) | 두 칸의 이름·설명 삭제. 묶음 이름 "갱신 주기 · 알림 기록" → "갱신 주기", 설명에서 "경제지표 알림 파일" 문구 삭제 |
| 설정 저장 (`Part3/lab/unified_settings.py`) | 두 키를 "더 이상 쓰지 않는 설정"으로 표시. 업데이트한 사용자의 `config.txt`에 줄이 남아 있어도 화면에 보이지 않고("기타 상세 설정"에도 안 나옴) 저장할 수 없습니다. 다른 설정을 저장할 때 남은 줄은 그대로 둡니다 |
| `Part1/program/config.txt` | 두 줄 삭제 |

새 시험 `Part3/tests/test_retired_settings120.py`(5건): 옛 `config.txt`에 두 줄이 있어도 화면에 안 보임, 저장 거부, 다른 설정 저장 시 파일의 나머지는 그대로, 배포 `config.txt`에 없음, 경제 작업자가 두 키를 무시하고 `event_state`에 기록함.
