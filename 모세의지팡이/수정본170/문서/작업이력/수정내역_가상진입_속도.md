# 가상 진입 계산 속도와 진행 표시 — 수정본33

진입·역크로스·손절·익절·동일 1분봉 손절 우선·스프레드 계산식은 그대로 두고 입력 읽기 범위를 줄였다.

## 읽기 경로

기존에는 요청 기간 전체를 CaptureInputs → STAFF로 다시 재생했다. 이제 알림마다 해당 날짜의 MSD2 키프레임에서 시작해 알림 시각 이후를 관측한다. 알림 TF와 1m의 `open`, `hma_6`, `hma_17`, `high`, `low`만 계산용 뷰에 보관한다. B0는 기존 알림에 기록된 값을 사용한다. 모든 손익비가 청산되거나 패스가 확정되면 해당 알림의 읽기를 끝낸다. 알림이 없으면 녹화를 읽지 않는다.

가상 진입 사후 계산만 STAFF 전체 경로를 통과하지 않는다. 전략 백테스트 본 실행은 기존 STAFF 수신·검증 경로를 그대로 쓴다. EA, Wire 및 MSD2 형식은 변경하지 않았다. 기존 무손실 형식 특성상 원래 번들 바이트 복원은 필요하며, 선택 열만 디스크에서 바로 읽는 새 저장 형식은 만들지 않았다. 날짜 키프레임과 알림 사이의 차분도 상태 복원을 위해 읽는다.

백테스트 본 실행에서 보조값을 별도로 저장하는 방식은 추가하지 않았다. 병렬 구간 경계를 넘어 대기·미청산 거래를 계속 추적하려면 별도 자료의 합치기와 보존 정책이 필요하다. 이번에는 기존 파일로 알림별 필요한 구간만 읽는 경로를 완성했다. 알림이 많고 오래 미청산이면 동일 날짜를 반복 복원하는 비용은 남는다.

## 진행·정지

`VIRTUAL_ENTRY_START/PROGRESS/COMPLETE`를 보내며, 진행률은 완료 알림 수와 현재 알림의 시간 진행을 함께 반영한다. 화면에는 `가상 진입 계산 중`과 처리 알림 수가 표시되고 백테스트 게이지가 가상 진입 단계로 전환된다.

정지 시 이미 관측한 거래의 9개 손익비 결과를 저장한다. 아직 처리하지 않은 알림은 성과에 넣지 않는다. `processed_signals`, `observed_signals`, 알림별 `processed_periods`, 마지막 확정 1분봉 시각을 결과에 기록한다.

## 시험

- 알림 0건이면 녹화 읽기 0회.
- 손익비 전부 청산 후 추가 입력을 읽지 않음.
- FULL/ROW/HEARTBEAT·키프레임의 선택 열이 기존 STAFF 뷰와 같음.
- 기존 가상 진입 경계 시험과 스프레드 시험 통과.
- 실제 XAU 입력에서 가상 진입 중 정지, 부분 CSV·결과 창 확인.

관련 로직 시험은 `current_logic_tests.xml`에 포함된다. 전체 결과/중단 표시는 `수정내역_백테스트화면_정지.md`에 기록했다.
