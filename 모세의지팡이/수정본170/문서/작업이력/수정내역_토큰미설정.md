# 텔레그램 토큰 미설정 로그 — 수정본33

빈 문자열 또는 공백만 있는 TELEGRAM_TOKEN이면 `텔레그램 토큰 미설정`을 한 번 기록하고 접속 루프를 시작하지 않는다. 기존 `접속 실패`로 표시하지 않는다. 실제 HTTP 출력 경로도 토큰이 없으면 sendMessage를 시도하지 않으며, 전송 성공 중복 방지 기록을 남기지 않는다.

진단 객체에서 미설정 안내를 한 번으로 제한하고 김비서 상태를 대기로 둔다. 유효한 토큰의 접속·재시도·전송 정책은 그대로다. 사용자 config와 토큰 값은 수정하지 않았다.

## 검증

- 공백 토큰으로 접속 루프를 두 번 호출해 안내 1회 확인.
- 빈 토큰으로 출력 호출 시 실제 transport 호출 0회, 성공 receipt 0건 확인.
- 모든 시험에서 네트워크 연결·전송을 차단했다. 실제 텔레그램 접속·전송은 하지 않았다.
- `검증결과/stop_virtual_parallel/current_logic_tests.xml`의 두 관련 시험 통과.
