# 백테스트 화면 수정

- `초기화 후 녹화`를 데이터 구축 모드에서만 표시하도록 변경했다.
- 알림 온리·가상 진입·데이터 구축을 전환해도 결과 옵션 카드 높이가 흔들리지 않도록 옵션 영역 높이를 고정했다.
- 데이터 구축에서 체크한 뒤 알림 온리 또는 가상 진입으로 전환해도 체크 상태는 보관하되, 해당 모드의 실행 요청에는 `rebuild=false`를 전달한다.
- 변경 범위: `Part3/web/unified.js`, `Part3/web/style.css`, `Part3/tests/test_unified_web.py`. Part1·Part2 엔진과 백테스트 판정은 변경하지 않았다.
- 검증: JavaScript 구문 검사 통과, Part3 테스트 56건 통과. 실제 웹 화면에서 알림 온리·가상 진입은 숨김, 데이터 구축은 표시, 체크 후 알림 온리 복귀 시 다시 숨김을 확인했다. 백테스트 실행은 하지 않았다.
