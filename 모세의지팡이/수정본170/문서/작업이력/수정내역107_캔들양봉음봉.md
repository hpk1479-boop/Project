# 수정본107 — AI 전략의 캔들 양봉·음봉 조건

수정본106에서 별도 수정본107을 만들었습니다. 이전 검증결과, 완성된 배포물, 빌드 준비 캐시를 복사하지 않았습니다. 수정본106의 프로그램·설정 파일 2,739개 해시를 비교해 변경 없음을 확인했습니다.

## 추가한 조건

- 공통 Recipe 조건 `CANDLE_STATE`에 시간봉과 `side=BULL/BEAR`, `bar_state=FORMING/CLOSED`를 명시합니다.
- 양봉은 해당 봉의 현재가격/종가가 같은 봉의 시가보다 높은 상태입니다. 음봉은 낮은 상태입니다. 같으면 어느 쪽에도 해당하지 않습니다.
- `FORMING`은 진행봉, `CLOSED`는 마지막 확정봉입니다. 봉 기준이 없는 JSON은 검증에서 거절합니다. 자연어의 현재 봉 요청은 진행봉으로 해석하도록 공통 의미를 설명합니다.
- 캔들 방향은 매수·매도 방향과 독립입니다. 음봉일 때 매수 같은 조건도 표현할 수 있습니다. 기존 `TREND`의 이동평균 추세와 혼용하지 않습니다.
- 차트 색상만으로 양봉·음봉을 추정하지 않습니다.

예: “1시간 진행봉이 양봉인 동안에만 1분 매수 일반 올존 알림을 받는 전략을 만들어 주세요.”

이처럼 최종 올존 시점까지 유지되어야 하는 조건은 `final_conditions`에 전달합니다. 공통 실행 포트는 알림 순간의 최신 입력으로 다시 판정하므로, 앞서 양봉이었다가 음봉으로 바뀐 상태에서는 알림을 허용하지 않습니다. 기존 사건 순서·취소·수명 규칙을 바꾸지 않았습니다.

## 공통 실행·화면·배포

계산은 공용 Fact `candle_direction` 한 곳에서 담당합니다. pandas·NumPy·이벤트 Fact는 같은 수식을 사용하며, 진행봉과 확정봉 접근은 기존 공유 캐시를 이용합니다. 잘못된 값이나 사용할 수 없는 데이터로 조건을 허용하지 않습니다.

AI 계약·공통 사전·로컬/원격 AI에 전달하는 정적 의미 정의에 동일하게 추가했습니다. 문장별 하드코딩, 자동 JSON 보정, 예외 해석 경로는 추가하지 않았습니다.

Part3 핵심요약·상세보기에서 양봉/음봉과 진행봉/확정봉을 확인·수정할 수 있습니다. 화면 배치는 그대로이며 기존 FVG 등의 표시도 유지했습니다. 생성 전략은 기존 메인전략 승급 절차로 Part1·Part2에서 사용합니다. 알림 문구에도 캔들 조건과 봉 기준이 표시됩니다.

수정본107에서 배포를 만들면 현재 공통 계약·Fact·판정 코드·AI 사전·화면이 함께 들어갑니다. 실제 배포 준비 함수로 소스가 노출되지 않는 코드 묶음을 만들고 별도 프로세스에서 개발본과 동일한 결과를 확인했습니다. Part3 생성·승급 전략을 기본 배포에서 제외하는 규칙은 유지했습니다. 배포 확인을 위해 완성 설치 EXE를 새로 만들지는 않았습니다.
