# 수정본113 AI 가상진입 연결

Part3 AI 백테스트 요청이 수동 백테스트와 같은 `virtual_entry` 계약을 사용한다. 전략 알림 발생 조건과 알림 이후의 가상 체결·필터·손절 조건은 분리한다.

## 적용한 내용

- `command.request.virtual_entry`에 Part2의 공통 JSON schema를 그대로 포함했다. 별도의 자연어 정규식이나 문장별 예외 해석은 추가하지 않았다.
- 실제 외부 AI에 전달되는 공통 allowlist와 안내에 즉시/확인 진입, 추가 확인 조건, ATR 필터·손절 의미를 포함했다. `research_interpreter`에만 안내를 써 놓고 실제 provider에서는 빠지는 상태를 방지했다.
- 사용자 지정 정책은 공통 `normalize_virtual_entry`로 검증한다. 미지정은 저장 정책을 사용하며, 설정이 바뀌면 이전 실행 확인은 무효가 된다.
- 연구 계획의 미지정 결과 방식은 현재 연구 기본인 가상진입으로 정해진 후, 실제 확인할 결과 방식과 정책을 편집표에도 반영한다. 날짜·종목만 다시 요청할 때도 그 전체 정책을 유지한다.
- 기존 SPECIAL/WATCH 및 생성 파일 모두 동일 정책을 전달한다. 생성 파일 실행의 별도 adapter도 공통 Part2 scenario에 정책을 포함한다.
- 실행 전 안내와 AI 계획 핵심요약에 현재봉 시가 진입, MA 종류·기간·시간봉, 인걸핑·해당 올존 넥라인, 봉 몸통/전체 길이·MA 거리의 ATR 범위, 손절 방식을 표시한다.
- 확인 진입은 직전 확정봉 매수 양봉/매도 음봉 마감 뒤 현재봉 시가, 즉시 진입은 알림 시점 가격으로 안내한다. 각 정책에 포함된 다른 확인 조건과 필터는 별도로 명확히 표시한다.
- 결과 방식을 알림만으로 바꾸면 가상진입 요약을 숨긴다. 상세보기 왕복과 결과 방식 변경은 저장된 정책 객체를 삭제하지 않는다.

## 검증

- 신규 `tests/test_virtual_ai113.py` 17개: 공통 schema 공유, 잘못된 계약·ATR 경계 거부, 세 실행 대상 전달, 저장 설정 반영, provider allowlist 두 단계 보존, scripted AI 결과 검증, 확인한 계획 실행, 생성 adapter 전달, 편집표 검사.
- 관련 계약·외부 provider·캔들 상태·보안 회귀까지 132개와 9 subtests 통과. 증거는 `검증결과/revision113/ai/tests_final.xml`이다.
- 새 실제 Edge 검사 5개 통과. 정책 표시, 알림만 전환, 재전환, 즉시 진입 표시와 정책 보존을 확인했다. JavaScript 오류 및 네트워크 호출은 없었다. `검증결과/revision113/ai/ui_report.json`, `ai_policy_core.png`에 기록했다.
- 기존 핵심요약·상세편집 실제 Edge 회귀 21개 통과. 조건·참조·분기·실행계획 보존과 360px 화면 확인을 포함한다. `검증결과/summary109/ui_report.json`에 이번 수정본에서 새로 생성한 증거를 기록했다.
- 실제 Gemini·텔레그램·MT5·시장 데이터 백테스트는 이 검증에서 실행하지 않았다. scripted JSON과 네트워크를 차단한 표시 검증을 사용했다.

`수정본112`는 보존했다.
