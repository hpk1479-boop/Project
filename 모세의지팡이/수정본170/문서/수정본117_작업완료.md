수정본116에서 이어 만든 수정본입니다. 이전 수정본 폴더는 건드리지 않았고, `검증결과`에는 이번에 새로 만든 증거(`revision117/`)만 있습니다.

| 설정의 기록 항목 | LIVE 기록 폴더 입력칸 | **라이브 알림 기록: 사용 / 사용 안 함**(기본 사용). 폴더 입력칸 삭제 |

### 라이브 알림 기록 자세히
- 설정 값은 `Part1/program/config.txt`의 `LIVE_RECORD_ENABLED`(true/false)입니다. 값이 없으면 사용으로 처리합니다.
- 업데이트는 받는 사람의 기존 `config.txt`를 그대로 유지하므로(설치 프로그램의 보존 규칙), 이 줄이 없는 옛 파일에서도 설정 화면이 기본값(사용)을 보여 주고, 처음 저장할 때 줄을 추가합니다. 다른 줄은 바꾸지 않습니다.
- 폴더를 만들 수 없거나(쓰기 권한 없음 등) 기록하다 실패해도 알림 전송은 계속하고 로그에 한 번만 남깁니다(기존 동작 그대로).
- 기록 위치는 프로그램 폴더 기준이라 폴더를 옮기거나 이름을 바꿔도 기록이 같이 따라가고, CSV에는 절대 경로가 들어가지 않습니다. 개발자의 `LIVE_기록`은 배포본에 들어가지 않고, 업데이트 때 설치 폴더의 기존 기록은 지워지지 않습니다(설치 프로그램은 배포 목록에 있는 파일만 교체).
- 삭제: 컴퓨터별 폴더 지정 모듈(`Part1/program/machine_roots.py`)과 연결 설정의 `live_records`. 쓰는 곳이 없어졌습니다.
- 이전에 지정해 둔 폴더(`%LOCALAPPDATA%\THE_STAFF_OF_MOSES\roots.json`)는 더 읽지 않습니다. 그 폴더의 옛 기록은 그대로 남아 있고 이동하지 않았습니다.

| 확인 | 결과 |
|---|---|
| 통합설치 자체 시험 | 440건 통과 |
| 배포 시작 점검(`모세의지팡이 배포.ps1 -CheckOnly`) | `CHECK_ONLY_OK` |

| 배포 폴더에서 실제 실행(코드 묶음 설치 후) | 기록 폴더가 설치 폴더 안에 자동 생성되어 기록됨. 사용 안 함이면 폴더도 파일도 안 생김 |
