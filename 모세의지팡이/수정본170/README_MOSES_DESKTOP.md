# MOSES 전용 창 실행

**AI 전략연구** 제목 옆의 작은 **전략생성 / 챗** 버튼으로 모드를 선택합니다. 기본은 전략생성입니다. 챗에서는 전략 아이디어·조건 차이·백테스트 방법을 대화로 논의할 수 있습니다. 두 모드 모두 전략 작성·수정과 백테스트를 요청할 수 있으며, 같은 대화와 직전 canonical 해석을 유지합니다. 대화에서 제안한 조건을 사용하려면 **그 조건으로 만들어** 또는 **수정해**처럼 요청한 뒤 기존 해석 확인 버튼을 누릅니다. 백테스트도 실행 계획을 확인한 뒤 시작합니다.

논의만 한 경우에는 현재 전략이나 파일·작업을 변경하지 않습니다. 이전 해석의 확인 버튼이 남아 있다면 그 버튼은 이전 해석에 대한 것입니다. **대화 새로 시작**은 선택한 모드를 유지하고 두 모드의 대화·직전 해석을 함께 초기화합니다. 실행 중인 백테스트와 생성 파일은 유지합니다. 최근 대화만 모델에 전달하며 현재 canonical intent와 백테스트 계획은 별도로 전달합니다. 모델이 지원 범위 밖의 조건을 제안해도 기존 schema·validator가 생성과 실행을 차단합니다.

백테스트 설정의 **동시에 사용할 작업 수**와 **백테스트 작업 구간 크기**는 접힌 **상세 설정**에 있습니다. 동시 작업 수를 비우면 컴퓨터의 물리 코어 수를 사용하며 기존 최대 12개 제한은 없습니다. CPU 사용률·메모리를 측정해 작업 수를 바꾸지는 않습니다. 실제 실행 프로세스 수는 생성된 작업 구간 수를 넘지 않습니다. WATCH 명령이 포함되면 한 번 감시의 소진 상태와 진행 중 조건을 유지하기 위해 전체 기간을 엔진 하나에서 연속 재생합니다. 이 경우 요청한 작업 수와 관계없이 실제 동시 작업은 1개이며 진행·결과에 그 이유를 표시합니다. 직접 조정할 때는 기존 숫자 입력을 사용하세요.

작업 구간 크기의 기본값은 **자동**입니다. 명령이 없는 일반 재생은 기간과 작업 수에 맞춰 월→주→일 분할을 선택하며 월·2주·주·일 선택도 유지합니다. WATCH 명령이 있는 재생은 선택한 구간 크기와 관계없이 상태를 이어서 처리합니다. 기존에 직접 저장한 작업 수나 구간 선택은 덮어쓰지 않습니다. 데이터 구축의 월·일 캡처 조각은 재생 작업 분할과 별개입니다. 필요한 구간을 덮는 정상 캡처는 재사용하며, 휴일 때문에 실제 준비 거래일이 부족하면 추가 구축 계획을 확인한 뒤 진행합니다. 준비 일수를 임의로 줄이지 않습니다.
